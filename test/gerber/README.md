# Gerber test fixtures

This directory contains fabrication archives used by Gerber-viewer import
tests. Keep each archive unchanged after it is added, and record its origin,
checksum, contents, and parser-validation result beside it.

- `generated/gerbolyze-protoboards/` contains locally generated Gerber and
  Excellon packages based on Gerbolyze protoboard definitions.

The fixture provenance does not rely on or include KiCad source code.
