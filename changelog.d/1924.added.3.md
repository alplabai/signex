- **`signex-cli` works through a running Signex (#1924)** — `signex-cli run <project>` now sends its commands to a running Signex that has the project open (with "Allow agent connections" on), so you see the agent's edits appear live while you keep your tab, selection, tool and focus; with no such Signex it runs headless as before and holds the project for the run. `--attach` and `--headless` force one way and fail if it cannot be done; every result line now says `"mode": "attached"` or `"headless"`. The edits stay unsaved in your Signex until you save them; with `--save` an agent can save a project file too, when it and every library the save would write are inside the run's folders.
