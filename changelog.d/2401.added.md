- **Layer stack manager and per-layer via and pad sizes (#2401)** — Design ▸ Layer Stack Manager... opens a table of the board's physical stack: name, type, material, thickness, Er and copper weight per layer, with the total thickness. Add signal, plane and dielectric layers, remove or reorder them, each one undo step; new copper layers appear in the layer tabs and items move with their layer. Vias and pads can size their copper per layer (top/middle/bottom or every layer); the board draws the size on the active layer and the design rule check reads it on each layer.
