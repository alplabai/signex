- **Breaking: footprints and boards with a suppressed linear pattern instance need this version or later (#2688)** — a footprint file whose sketch has a linear pattern with a suppressed instance is written as `snxfpt/1.5`, which older Signex builds refuse to open, and a board whose sketch has one as `snxpcb/1.13`, which older builds open read-only, rather than bake the suppressed pads and drop the list on save. Files without one keep their format and bytes. Keep a copy made with the older build if you still need to open it there.
