- **A placed library part always draws with the library's current symbol; older parts keep their version until you update them (#2209)** — a symbol edited in its library after it was first placed on a sheet used to be ignored by later placements, which drew the old copy. A sheet now embeds one body per version (`<lib_id>#<hash>`, named by `body_ref` on each symbol in the `.snxsch`), so old and new versions coexist and nothing changes on a placed part without Properties > Update from library, which moves every instance of the part (or just the chosen one) as one undo step. Format change: the `.snxsch` version is now `snxsch/1.1`; older Signex builds open these files read-only (a save is refused) instead of showing parts without pins, and the copy-paste text marker is now `signex-clipboard-fragment/2`, so an older build treats a new copy as plain text and paste does nothing there. A sheet saved before this change is upgraded once on load and written in the new form on its next save.
