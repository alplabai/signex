- **DRC results panel on boards (#2399)** — Tools ▸ DRC Results lists the last design rule check of the board grouped by rule with counts. A click on a violation selects its objects and centres the view on it; filter by rule, layer and severity; waive a violation with a note (stored in the board, one undo step) and unwaive it. The list is marked stale when the board changes after the run. Every action is also a command an agent or a script can run.
