- **Import Library previews in deep folders on Windows (#3234)** — A library folder of about 211 characters or more, such as one deep in a synced Documents folder, put the hidden preview folder past Windows' 260-character limit: Import then always failed, and Back, Cancel, closing the dialog and quitting left the hidden folder on disk. The import's own Windows calls now use the long form of the path, so such a preview moves into place and is removed like any other, and a library folder that is itself longer than 260 characters is accepted again.
- **A second Signex no longer removes a preview another one is showing (#3234)** — Opening Import Library cleaned up hidden preview folders older than an hour, including one another running Signex still showed, whose Import then failed while offering another try. A running Signex now holds a lock on each preview it shows, the clean-up leaves a locked preview alone however old it is, and an Import whose preview folder has gone no longer offers to try again.
