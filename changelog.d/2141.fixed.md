- **A Component Preview row and a project are recovered after a crash (#2141)** — with autosave on, a row with unsaved edits is written as a JSON snapshot and a modified project as the `.snxprj` it would save, both in the recovery folder the sheet copies use. The next time the row or the project opens, the same Recover Unsaved Edits prompt offers the copy back: Restore loads it as unsaved edits, Discard deletes it. A save removes the copy. Half-typed parameter text, PDFs picked but not yet saved, and libraries still waiting to be created are not part of the copy.
