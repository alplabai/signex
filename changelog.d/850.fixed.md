- **Dock layout saves no longer stall the UI (#692)** — hovering a dock tab or dragging a floating panel no longer rewrites `prefs.json` on every event; the layout is written only when it changed, once, 500 ms after the last change and off the UI thread. Quitting saves the latest layout, including a retry after a failed write, and a layout that cannot be saved (or a damaged `prefs.json`) is reported once in the Messages panel instead of repeatedly.
