- **The Passive Network Calculator has the Graphite layout (#2262)** — the body no longer repeats the dialog title (nor "RKM Encoder" on its tab); Resistor / Capacitor / Inductor / RKM Encoder is a segmented control; the inputs sit on one line with their labels above, and the SI prefix and unit (Ω, F, H) sit inside the Target and RKM Value fields, so the separate Unit dropdowns are gone. The result reads `R1 + R2 = 4.52 kΩ` with a pill saying how far the nominal value is off the target (green within the series tolerance, amber past it), then one Target / Nominal / Minimum / Maximum strip with each Δ under its value (they were three more read-outs), and a small series/parallel drawing beside the part cards; hovering a part in the drawing outlines its card. Part names read `R1`, not `R₁`. Each card still has an editable tolerance and its colour code. On the RKM Encoder tab, temperature coefficient and rated power fold into an "Optional" section, and the production date code is switched on by its own checkbox: while it is off the Cycle / Year / Month pickers are greyed, the code reads "Off" and the picks are kept; the first time it is switched on they start at this month. The "Clear production date" button is gone. Narrow windows stack the inputs, the strips and the cards. Every word in the calculator now comes from the message catalog.
