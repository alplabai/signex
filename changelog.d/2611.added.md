- **Design Notebook PDF export (#2611)** — File ▸ Export ▸ Design Notebook PDF… exports the project's notebook with a choice of pages, paper, variant, title block, contents, bookmarks, Python source and annotation kinds. It checks the notebook's part, pin and net references first: a stale one prints with a margin mark, or fails the export if you choose. The PDF has a bookmark for every section, subsection, figure and table. Two exports of the same notebook give the same file, and the done card shows its checksum. The default file is `Project Outputs/notebook/<project>-<document>-rev<R>.pdf`, and `signex-cli notebook export-pdf --project <p>.snxprj` does the same export from the command line.
