- **Placement commands run from operands (#2155)** — a command run by id with operands (`place_net_label at=5.08,10.16 text=VCC`, the wire, bus, line, rectangle, text, junction, no-connect, no-ERC and power commands) now places the object through the same commit a canvas click uses, so undo and the Messages log behave as for a click; the active tool is left as it was. A point off the snap grid, or a zero-length segment, is refused with the reason instead of being moved. File-dialog commands still refuse operands until a follow-up.
