- **Object List panel (#1259)** — the SCH List panel is now the Object List (View ▸ Panels ▸ Object List). It lists every part, label, wire, power port, port, sheet symbol, sheet entry, text, junction, bus, drawing and directive of the sheet in view or of the whole project, with a filter, kind chips with counts and the sheet each object is on. A click selects the object on the canvas (opening its sheet when needed), a double click zooms to it, and rows selected on the canvas are marked. A saved dock layout that held SCH List opens without it.
