- **Board placement tools (#2373)** — on a board, Place and the PCB Active Bar now run the Via and Track tools. Via places a through via on the grid with the board's via size, on the net of the copper under it. Track draws a run on the active copper layer on the net it starts on, bending like a wire (Space flips the corner, Shift+Space changes the corner mode); changing the copper layer mid-run adds a via. Each click is one undo step; Esc or a right-click ends the run, then the tool.
