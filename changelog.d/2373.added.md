- **Board placement tools (#2373)** — on a board, Place and the PCB Active Bar now run the Via, Track, Fill and Solid Region tools. Via places a through via on the grid with the board's via size, on the net of the copper under it. Track draws a run on the active copper layer on the net it starts on, bending like a wire (Space flips the corner, Shift+Space changes the corner mode); changing the copper layer mid-run adds a via. Fill (two corners) and Solid Region (a corner per click, closed on its first corner or with a right-click) add solid copper on the active copper layer. Each click or finished shape is one undo step; Esc or a right-click ends the shape, then the tool.
