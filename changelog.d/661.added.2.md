- **Board edits have one home (#661)** — an open PCB now holds a board engine: every board edit is a board command with an exact inverse, on one undo history with a save point and the shared `undo_depth`. Undo and Redo (menu, keys, `undo` / `redo`) step a board when its tab is active, undoing back to the saved board reads clean, and a dirty board closed or quit still prompts and keeps its undo history when reopened. No editing tool uses it yet; agents can apply a labelled step that is refused if the board moved past the revision they read.
