- **Layer colours on the layer tabs, saved with the board** — a layer tab's right-click menu has Layer colour..., which opens the Layers panel's colour picker for that layer, Reset layer colour and Reset all layer colours. A picked colour is saved in the `.snxpcb` (`[board_options.layer_colors]`), is one undo step and marks the board changed; the canvas, the tab swatch and the Layers panel draw the layer in it. A board with layer colours saves as `snxpcb/1.5`, so an older Signex opens it read-only instead of dropping the colours; a board without stays `snxpcb/1.4`, byte for byte.
- **Hide layers ▸ and Show layers ▸ list the layers one by one** — under each kind (Signal, Plane, Silkscreen, Mask, Paste, Mechanical) the flyout lists the layers that row would change, each hiding or showing that layer alone.
- **Edit ▸ Origin** — Set puts the board origin where you click next (`E O S`, or `Shift+O` in the Classic keys), Reset moves it to the bottom-left of the board outline, and Snap to Outline Corner moves it to the outline corner nearest the pointer. Each is one undo step and is saved with the board, so a board made before the origin existed can count from its bottom-left corner too.
