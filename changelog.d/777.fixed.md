- **Renaming a project library keeps the project pointing at it (#739)** — a project-local `.snxlib` can now be renamed from the project tree. The file move and the re-point happen in one update, like a sheet rename: the `LibraryEntry` path follows (relative stays relative), and the mounted library, its open editors, browser tabs, pickers and dirty markers move to the new path, so no edit can recreate the old file or miss the renamed one. The `.snxprj` is marked unsaved rather than written (Save, Close Project and quit prompt for it) and a Messages-panel entry says so; a library kept in its own repository records the rename as a commit. Shared and Global libraries are still refused (#657).
