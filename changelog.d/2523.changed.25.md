- **Board component Properties in the Graphite layout (#2523)** — with components selected on a board, Properties shows the component pill and footprint name, General / Parameters tabs with the parameter count, the row search, and a line-art drawing of the footprint (pads in the side's copper colour, the courtyard when the footprint draws one, pin 1, the designator and the side); hovering a field lights its part of the drawing and back. Location carries the lock in its header and X and Y on one Position row; Layer is a Top / Bottom switch; 3D Opacity is a slider with the typed value box beside it; Lock Primitives and Lock Strings share one Lock row; the footprint picker button reads Change…; Swapping Options starts closed. The General Description row edits the component's Description parameter, and Channel Offset and the footprint Description are typed rows; Area, Library and the rest of Schematic Reference Information are read-only, and a designator that differs from the schematic's comes with an Update PCB button.
