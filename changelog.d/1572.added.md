- **Typed component values: number field, SI prefix picker, fixed unit (#1572)** — the Edit Component Details modal and the component editor's Parameters tab edit a measurement as a plain number, an SI prefix picked from a list (`kΩ`, `µF`; hidden for `%`, `ppm/°C` and other units without prefixes) and the unit. Typing `4k7` or `4.7uF` into the number field is refused with a message. Values are stored as the base value and the unit token (4.7 with `k` on an ohm slot is `{4700, "ohm"}`), and committing a number that did not change leaves the stored value, and so its content hash, as it was. A measurement in a unit the editor does not know keeps its text editor and its unit string.

  The Library Browser's measurement cells open the Edit Component Details modal instead of taking raw text: a 90 to 110 px column has no room for a number field and a prefix picker. The Parameters tab now shows why a value breaks its template (zero capacitance, a negative R, C or L, wrong unit or kind) beside the slot. The library diff shows the raw stored values when two parameter values display alike, so a legacy `{4.7, "kΩ"}` becoming `{4700, "ohm"}` no longer reads as `4.7 kΩ → 4.7 kΩ`.
