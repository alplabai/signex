- **"Did you mean" for unknown command ids (#2326)** — An agent's call with a command id the catalog does not have is refused with up to three close catalog ids (`unknown command `plce_wire`; did you mean `place_wire`?`), and the Messages warning for a keyboard-shortcuts profile entry with an unknown id ends the same way. An id with none close, a very short one or a very long one keeps the old text.
- **Swap and reuse-block place name their component by uuid (#2326)** — `swap_pins`, `swap_gates` and `place_board_reuse_block` take `ids=<uuid>` as well as `designator`, exactly one of the two; both, neither, more than one uuid or a uuid that is no component of the board is refused. The board menu now names the clicked component by uuid, so it keeps acting on that component where a designator is shared.
