- **Generate design notebook (#2945)** — one command builds a design report from the project: requirements and how each was met, the architecture, key decisions, a BOM summary, ERC, DRC and requirement results, simulation results, outputs produced, open items and the change log. It is its own file, `notebook/generated/design-report.snxnbk`, that Regenerate replaces; your own notebook pages are never changed. Run it from command search (with an options dialog), as `generate_design_notebook`, or from a terminal with `signex-cli notebook generate --project <file>.snxprj --json`, which exits 0 unless `--fail-on requirements` (or `checks`) names a failure and replaces an existing report only with `--force`.
