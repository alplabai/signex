- **Library server refuses plaintext on a non-loopback bind (#115)** — `signex-library-server` now exits at startup unless `--allow-insecure-bind` (or `SIGNEX_ALLOW_INSECURE_BIND=1`) is given, since it has no TLS and must sit behind a TLS-terminating proxy. A `@signex-keychain:<name>` library `auth` is now resolved through the OS keychain instead of being rejected, and `SIGNEX_TRUSTED_PROXIES` lets the rate limiter key by the real client behind a trusted reverse proxy rather than sharing one bucket.
