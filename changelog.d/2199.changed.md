- **Breaking for headless callers: wires and buses from operands are checked and answer with data (#2199)** — `place_wire`, `draw_wire`, `place_bus` and `draw_bus` run from `start` and `end` now refuse a run that touches something it was not drawn to, crosses a symbol body, is not horizontal and vertical, or leaves an end unconnected, and the CLI reports `answered` with the run's report instead of `ran`; `apply_edits` includes each edit's answer in `results`. Pass `allow_open=true` for a deliberately open end. A click on the canvas is unchanged.
- **Breaking for headless callers: a label or power port from operands that would rename a net is refused (#2199)** — `place_net_label`, `place_local_net_label`, `place_global_label`, `place_hierarchical_label` and `place_power_symbol` run from `at` (a coordinate or a pin reference) are refused when the net already at that point has another name, because the two would short; pass `allow_merge=true` to merge on purpose. The same name, an unnamed net or an empty point is allowed.
