- **Breaking for headless callers: wires and buses from operands are checked and answer with data (#2199)** — `place_wire`, `draw_wire`, `place_bus` and `draw_bus` run from `start` and `end` now refuse a run that touches something it was not drawn to, joins differently named nets or buses without `allow_merge=true`, crosses a symbol body, is not horizontal and vertical, or leaves an end unconnected, and the CLI reports `answered` with the run's report instead of `ran`; `apply_edits` includes each edit's answer in `results`. Pass `allow_open=true` for a deliberately open end. A click on the canvas is unchanged.
- **Breaking for headless callers: labels, power ports, junctions and no-connects from operands are checked for shorts and joins (#2199)** — `place_net_label`, `place_local_net_label`, `place_global_label`, `place_hierarchical_label` and `place_power_symbol` run from `at` (a coordinate or a pin reference) are refused when the net already at that point carries other names and not the new one, and `place_junction` is refused when it would join two nets with different names; pass `allow_merge=true` to merge on purpose. A label, power port, junction or no-connect placed by pin reference is also refused, with no escape, when it would pull another net onto the pin's (a wire passing under the tip, or another pin on it). The same name, an unnamed net or an empty point is allowed.
