- **Breaking for headless callers: wires and buses from operands are checked and answer with data (#2199)** — `place_wire`, `draw_wire`, `place_bus` and `draw_bus` run from `start` and `end` now refuse a run that touches something it was not drawn to, joins differently named nets or buses without `allow_merge=true`, crosses a symbol body, is not horizontal and vertical, or leaves an end unconnected, and the CLI reports `answered` with the run's report instead of `ran`; `apply_edits` includes each edit's answer in `results`. Pass `allow_open=true` for a deliberately open end. A click on the canvas is unchanged.
- **Breaking for headless callers: labels, power ports, junctions and no-connects from operands are checked for shorts and joins (#2199)** — `place_net_label`, `place_local_net_label`, `place_global_label`, `place_hierarchical_label` and `place_power_symbol` run from `at` (a coordinate or a pin reference) are refused when the net already at that point carries other names and not the new one (a hierarchical label is a port and renames nothing; a short through its entry is still refused), and `place_junction` is refused when it would join two nets with different names; pass `allow_merge=true` to merge on purpose. A label, power port, junction or no-connect placed by pin reference is also refused, with no escape, when it would pull another net onto the pin's (a wire passing under the tip, or another pin on it). A name the net already carries (an alias included), a net that carries no name or only aliases, or an empty point is allowed. Names are judged across the project by one frozen rule (https://github.com/alplabai/signex/issues/2199#issuecomment-6761836527): a net's own names are its net labels, global labels/ports and power ports, its aliases the names of hierarchical labels; two own-named nets with different own names are a short, an own-named net joins an alias-only one freely, two alias-only nets are a short only when they share no name, and only a new own name renames. Each edit is judged by what it changes: a child's local labels already behind a hierarchical label before the edit play no part, names the edit brings behind a port count, so the same final design reached in another order can get another verdict; a global `SDA_INT` placed in a child whose local `SDA_INT` is behind its port is a rename unless `allow_merge=true`. Where the project check runs, its name verdict is the only one. Buses follow the same rule with bus names (hierarchical bus labels are aliases), and a bus run ending on a sheet entry is no longer refused as open. The check on one sheet follows the same rule for loose sheets and nets that reach no other sheet. A bus run ending on a lone bus-name label merges that name by the same rule. A run's answer, a bus run's included, lists the aliases of the joined net in `aliases`. A no-connect and a power flag are not judged. When the project cannot be read completely and the net reaches another sheet, the edit is refused with the reason unless `allow_merge=true`.
