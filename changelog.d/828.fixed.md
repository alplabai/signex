- **The remaining numeric text inputs refuse `NaN`/`inf`, and library files refuse to save or load them (#828)** — the footprint sketch preview, Component Preview and Library Browser parameter cells (including the edit modal), the symbol editor pin and graphic fields and the Move Selection dialog now keep the stored value when `nan`, `inf` or an overflowing number is typed. All of these except the sketch preview log the refusal to the Messages panel. A Move Selection with one refused axis now moves nothing and keeps the dialog open, instead of moving along the other axis. A refused or unchanged symbol-editor keystroke no longer records an undo step or marks the tab dirty. Saving a `.snxsym` or `.snxfpt` that holds a non-finite number now fails with an error naming the pin or pad cell or the key path, instead of silently writing an empty cell (release) or panicking (debug), and the file on disk stays unchanged. The `[extras.*]`, manifest, stackup and zones tables of `.snxsch` and `.snxpcb` get the same refusal, and a footprint pad shape with a non-finite ratio or custom point is rejected on load. An expression with more than 256 chained operators now reports that the chain is too long rather than that it "nests deeper than 256 levels".
