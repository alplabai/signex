- **The remaining numeric text inputs refuse `NaN`/`inf`, and library files refuse to save them (#828)** — the footprint sketch preview, Component Preview and Library Browser parameter cells (including the edit modal), the symbol editor pin and graphic fields, the Move Selection dialog and the selected-element rotation now keep the stored value when `nan`, `inf` or an overflowing number is typed, and report the refusal in the Messages panel. Saving a `.snxsym` or `.snxfpt` that holds a non-finite number now fails with an error naming the pin or pad cell or the key path, instead of silently writing an empty cell (release) or panicking (debug), and the file on disk stays unchanged. The `[extras.*]` tables of `.snxsch` and `.snxpcb` get the same refusal. An expression with more than 256 chained operators now reports that the chain is too long rather than that it "nests deeper than 256 levels".
