- **Schematic Properties rows follow the new form layout (#2523)** — a placed object's Position (or a wire's Start) is one row with the X and Y fields side by side and the unit inside each field, a sheet symbol's Size is one W / H row, and Rotation is a 0° / 90° / 180° / 270° switch instead of a drop-down. A wire's Width is a 2 × 2 grid of Smallest, Small, Medium and Large, and its Color field opens a small menu with the preset colours, Custom… and Reset to Default.
