- **Fabrication outputs (#2388)** — File ▸ Fabrication Outputs, the PCB Active Bar and the palette open one dialog that writes the board's Gerber RS-274X files with X2 attributes (each copper layer, legend, solder mask, paste and the board profile), Excellon drill files (plated and non-plated apart, with slots, and one file per blind or buried via span) and a drill table, a pick-and-place CSV, an IPC-D-356 test netlist and a job file listing them. Nothing is written until you press Generate, into the folder you choose, and the same board always gives the same files. Zone fills and board text are not in the files yet; the dialog and a warning in Messages say how many were left out, and older files of the same name left in the folder are listed so they are not sent with the new set.
