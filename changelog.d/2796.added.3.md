- **Block diagram export to SVG and PDF (#2796)** — a block diagram (`.snxblk`) is written as an SVG file at 1:1 in millimetres or as a PDF page fitted to A4 landscape with a title block: group frames, blocks in their shape and colour with their name, function, note and ports, and every connection with its arrow and its protocol label, power in red and buses thick. From the command palette it asks for the diagram (or takes the one in view) and the file; from the command line `export_block_diagram document=<diagram> path=<file>` (`kind=svg|pdf`, `monochrome`, `title_block`), which answers once the file is written.
