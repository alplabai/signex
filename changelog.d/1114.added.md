- **Text notes can be rich text (#1114)** — a text note's Properties gain a Format row, Plain or Rich text, and `set_text_note_format` sets it from the CLI or an agent. A rich note keeps Typst source as its text, stored in its own sheet; switching back to Plain keeps the text as it is. A sheet with only plain notes saves exactly as before. Drawing the Typst source comes in a later change; until then a rich note draws as a plain one.
