- **Rich text notes in Typst (#1114)** — a text note's Properties gain a Format row, Plain or Rich text. A rich note's text is Typst source, stored in its own sheet: headings, bold and italic, lists, math, tables and links draw on the sheet as sharp vector paths, and the SVG and PDF exports draw the same paths. Double-click a rich note (or Edit… in Properties) to edit it in place over the sheet, with the source on the left and the note as it will draw on the right, recompiled as you type; Ctrl+Enter applies as one undo step. The Frame and Size sections add a border or fill, padding, and a fixed width or box. A search hit inside a note opens its editor at the match, and Ctrl+click opens a note's link. Every action is a command for the CLI and agents. A sheet with only plain notes saves exactly as before.
