- **Extension API (#2495)** — a binary built on `signex-app` can install its own extensions at startup through `signex_app::launch::run`; each one receives its own messages and, in later changes, adds commands, panels, menu rows, Start-screen sections and preferences under an `ext.<name>.` id. The Community binary installs none and is unchanged. See `docs/EXTENSION_API.md`.
- **Extension catalog commands (#2495)** — an extension adds commands with ids under its own `ext.<name>.` prefix; they run through the same command path as built-in ones from a key binding, a menu row or a headless run, and each says whether it runs headless or only in a window. An id that is or reads as a built-in command, lies outside the prefix or repeats is refused, and the extension is not installed. Built-in command ids are unchanged.
