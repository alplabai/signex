- **Extension API (#2495)** — a binary built on `signex-app` can install its own extensions at startup through `signex_app::launch::run`; each one receives its own messages and, in later changes, adds commands, panels, menu rows, Start-screen sections and preferences under an `ext.<name>.` id. The Community binary installs none and is unchanged. See `docs/EXTENSION_API.md`.
- **One request path (#2495)** — menu rows, keys, the palette, the agent socket and `signex-cli` run a command through one function, `Signex::run_command_request`, and read its result as one typed outcome: answered, ran, refused (with why) or failed. An agent request can carry `if_revision`: it runs only while its document is still at that revision, and is refused with nothing changed once the document moved. See `docs/EXTENSION_API.md`, "One request path".
