- **Extension API (#2495)** — a binary built on `signex-app` can install its own extensions at startup through `signex_app::launch::run`; each one receives its own messages and, in later changes, adds commands, panels, menu rows, Start-screen sections and preferences under an `ext.<name>.` id. The Community binary installs none and is unchanged. See `docs/EXTENSION_API.md`.
- **Extension panels, rows, Start-screen sections and preferences (#2495)** — an extension adds dock panels (a stable `ext.<name>.` layout key, a title, a home dock region and its own view and update hooks), menu bar rows and PCB Active Bar rows that run its commands through the same path as every built-in row, sections in the Start screen's Home slot, and preferences kept in `prefs.json` under its own keys. A saved dock layout keeps an extension panel key whose extension is not installed and writes it back where it stood.
