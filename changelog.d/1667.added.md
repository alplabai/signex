- **Placement extras on a sheet (#1667)** — Autoplace Fields puts the reference and value of the selected parts back where autoplace puts them, fields you moved included, as one undo step. Copy Attributes arms another of the part, label, port or text note under the cursor with its look (a part with the next free designator). Place Design Block puts the content of another sheet file on the cursor, and Import Graphics puts the lines, circles, arcs and polylines of a DXF file on the cursor as sheet drawings; one click places either as one undo step. All four run from their keys and the palette; Place ▸ Design Block... and Import Graphics... and the right-click Part Actions ▸ Autoplace Fields and Copy Attributes reach them too, and `autoplace_fields`, `place_design_block` and `import_graphics` also run from operands.
