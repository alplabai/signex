- **Run Signex commands without a window: `signex-cli` (#1923)** — `signex-cli run <project> < commands.jsonl` opens a project headlessly, runs one catalog command per JSON line and prints one result line each (`ran`, `refused`, `failed`, with the reason, the Messages log and the documents that changed); `signex-cli commands --json` lists the catalog with each command's arguments, capability and whether it can run headless. Nothing is written without `--save`, paths must stay inside the project (or `--allow-path`), each command needs a named capability (`read,edit` by default), input is size-limited, every command is audited with a run id, and a headless run never opens, creates or commits to a git repository (a save logs "commit skipped in a headless run"). See `docs/CLI.md`. The GUI program is unchanged.
