- **A drawing value still being typed is no longer lost on Close Project (#3194)** — typing a value into a drawing's Properties box and then closing the project, from the menu or the project tree, used to close without a prompt and drop the value. Close Project now commits it as one undo step first, so the unsaved-changes prompt lists the sheet; a typo is put back as before. File ▸ Save All is available while such a value is being typed and saves it as one undo step.
