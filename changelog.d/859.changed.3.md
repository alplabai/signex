- **Saving a project's `.snxprj` no longer freezes the window (#859)** — Ctrl+S in the Project tab, Ctrl+S in a document tab, and Save All on close and quit now create the libraries added with New Library (their git setup included) and write the project file on one background job, in that order, so the file never lists a library that was not created. The project is marked saved only when the bytes written are still what it encodes to; an edit made while the write runs keeps it modified. A save asked for while one runs is queued once and runs when the first finishes, and a retry after an interrupted save adopts the library it left behind. A library that could not be created stays pending and the failure reaches the Messages panel, as before. Close Project and Quit wait for a write they start themselves and stay open if it fails; a Save All issued while a project write is already running keeps the window open with the "still running" reason.
