- **A half-typed parameter value is no longer lost silently (#2132)** — text in a Component row's number or measurement field that does not parse yet now counts as unsaved work. Closing the tab keeps the row parked with its text, Close Library, Close Project and Quit list the row, and File ▸ Save All is enabled for it. Save and Save All refuse the row with a message that names the field and leave the text in place; Discard drops it.
