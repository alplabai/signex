- **Pick a component's footprint (#1234)** — the Components panel details view now has a Footprint dropdown listing the part's default footprint and its alternates (for example 0402, 0603 or 1206 for a stock 0805 resistor); the preview follows the choice and Place from the Components panel builds the part with it. Placing a row from the library picker (not the Components panel) still uses the row's default footprint. A placed part whose row has alternates gets a Footprint dropdown in Properties above the existing Footprint text field, undoable, and the part remembers which footprint it was built with, so Library Updates no longer reports a part placed with an alternate as out of date. Older schematics load as before, with the row's default footprint.
- **Symbol and footprint previews fit the panel width (#2103)** — in the Components panel details view the symbol and footprint previews re-centre and re-fit when the panel is narrowed or widened, instead of drawing off-centre or clipping the last pad; a preview you have zoomed or panned keeps your view.
