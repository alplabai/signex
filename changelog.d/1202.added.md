- **Project tab (#1202)** — Project Options in the project tree now opens the project as a document tab instead of a read-only window. Its General section edits the project name and a new description, and shows the project folder, root schematic, PCB file and library count. Edits mark the project modified, Ctrl+Z / Ctrl+Y undo and redo them, Ctrl+S saves the project file without blocking the window, and closing the project or quitting asks about unsaved changes as for any other document. A changed name renames the `.snxprj` file when you save, since the project name is the file name. Projects without a description save exactly as before.
