- **Project tab (#1202)** — Project Options in the project tree now opens the project as a document tab instead of a read-only window. Its General section shows the project name with a Rename… button (the same rename as the project tree), edits a new project description, and shows the project folder, root schematic, PCB file and library count. Description edits mark the project modified, Ctrl+Z / Ctrl+Y undo and redo them, Ctrl+S saves the project file without blocking the window, and closing the project or quitting asks about unsaved changes as for any other document. Projects without a description save exactly as before. Renaming a project now also works when only the letter case changes, and File > Open Recent follows the renamed file.
