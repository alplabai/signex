- **Error cards, dialog window titles and file dialogs follow the language (#2058, first part)** — the error notice keeps its heading and detail as catalog messages and renders them with the language in force, so an open card changes on a language switch; the native title of every dialog window, the Create Sheet dialog, and the titles and file-type names of the native open and save dialogs come from the message catalog too. The text inside the other dialogs follows in a later change. System error lines, paths and file names are shown as they are. Log lines from the converted error cards keep English, except the New PCB / Update PCB refusals and the New Project pickers, which still follow the UI language for now. Two small changes to the English: counts of 1000 or more in the new count messages (Save All, Annotate, the BOM issue list, rename references) are grouped as "1,000", and the invisible bidirectional isolation marks are gone from error-card details, the board-sketch refusal bar, and the Messages lines for board-sketch held/refused and the New PCB refusals.
