- **Error cards, dialog window titles and file dialogs follow the language (#2058, first part)** — the error notice keeps its heading and detail as catalog messages and renders them with the language in force, so an open card changes on a language switch; the native title of every dialog window, the Create Sheet dialog, and the titles and file-type names of the native open and save dialogs come from the message catalog too. The text inside the other dialogs follows in a later change. System error lines, paths and file names are shown as they are, and log lines keep English. Two small changes to the English: counts of 1000 or more in the new count messages (Save All, Annotate) are grouped as "1,000", and the invisible bidirectional isolation marks are gone from error-card details and from the board-sketch refusal bar.
