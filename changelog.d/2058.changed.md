- **Error cards, dialog window titles and file dialogs follow the language (#2058)** — the error notice keeps its heading and detail as catalog messages and renders them with the language in force, so an open card changes on a language switch; the native title of every dialog window, the Create Sheet dialog, and the titles and file-type names of the native open and save dialogs come from the message catalog too. English text is unchanged; system error lines, paths and file names are shown as they are.
