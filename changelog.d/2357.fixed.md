- **PCB layer tabs switch the active layer (#2357)** — a click on a layer tab under the board canvas makes that layer the active one: the tab is drawn selected, the status bar layer readout follows, and the active copper layer draws on top. Any layer can be active now, not only copper (Top Overlay, Top Solder, Board Outline). `+` and `-` step through the board's layers in tab order, `*` steps to the next signal layer (new command `next_signal_layer`), and Shift+S turns single-layer mode on or off (new command `toggle_single_layer_mode`): only the active layer is drawn, with the board outline and the vias and through-hole pads that reach it. Both commands are in the View menu.
