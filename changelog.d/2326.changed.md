- **Message ids moved into the UI-free `signex-i18n-ids` crate (#2326)** — `MessageId`, the id constants, `Translatable`, `Arg`, `LocalNumber` and `UserText` now live in a crate with no Fluent, ICU or locale dependency, so the application core can report messages without rendering them (ADR-0006). `signex-i18n` re-exports them under the same paths and still does all the rendering; the text the app shows is unchanged.
