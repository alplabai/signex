- **Board items named by uuid are a `targets` operand (#2326)** — the `ids` operand of the board lock, via span, layer size, pad shape, gloss, board shape, keepout, arrange and measure commands is now of kind `targets` in `signex commands`: uuids, comma separated, each counted once, at most 10 000. An empty list, a part that is not a uuid or an id that names nothing the command acts on refuses the whole command with the reason; gloss, board shape and keepout used to run on the ids they knew and skip the rest. A keepout list naming both zones and lines is refused; it used to make keepouts from the zones and skip the lines. An agent may send `ids` as a JSON list of uuid strings.
