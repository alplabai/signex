- **Message ids moved into the UI-free `signex-i18n-ids` crate (#2326)** — `MessageId`, the id constants, `Translatable`, `Arg`, `LocalNumber` and `UserText` now live in a crate with no Fluent, ICU or locale dependency, so the application core can report messages without rendering them. `signex-i18n` re-exports them under the same paths and still does all the rendering; `render_en_us` and `localized` are now methods of the `signex_i18n::RenderTranslatable` trait, so code calling them imports that trait. The text the app shows is unchanged.
