- **Footprint sketch drags no longer freeze the editor while the solver runs (#1047)** — a drag tick moves the geometry at once and solves it on a background task; a result is applied only if no newer edit has happened since, and ticks that arrive meanwhile are coalesced into one follow-up solve. A drag is now one undo step, not one per cursor tick. During a continuous drag the pads, silk and constraint colours do not follow the cursor until it pauses for longer than one solve, because every result that arrives mid-drag is already stale. A save, an undo or redo, a footprint switch or any edit that records its own undo step first finishes the owed solve, so nothing unsolved is ever written or kept in undo history. Other sketch edits still solve inline.
