- **Pin references and a checked wire from the command line (#2199)** — a point operand also takes `<designator>.<pin>` (`R1.2`, `U1.VCC`), which is that pin's tip on the sheet the edit targets, off the grid or not: `signex-cli run demo.snxprj place_wire --arg start=R1.2 --arg end=C1.1 --save`. A wire from operands is checked before it lands and refused, with the reason, when its path also touches another pin, label, junction or wire, shorts two differently named nets (`allow_merge=true` allows it), crosses a symbol body, runs diagonally, or leaves an end connected to nothing (`allow_open=true` allows it). `dry_run=true` (`--dry-run`) reports the result without changing anything. A bus is checked for orthogonal segments, body crossing and dangling ends the same way. An accepted run answers with the segments, the net and its pins, and the names it merged.
