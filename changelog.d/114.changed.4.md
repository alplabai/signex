- **Inter is the default UI font, JetBrains Mono the chrome mono font (#114)** — Signex now bundles Inter (Regular, Medium, SemiBold) and JetBrains Mono (Regular, Medium) with their SIL OFL licences. Anyone who never picked a UI font gets Inter instead of Roboto; a font you chose is kept. Canvas text stays on Iosevka, so existing designs keep their text and extents. Active Bar dropdowns are a little wider to fit Inter's wider letters.
