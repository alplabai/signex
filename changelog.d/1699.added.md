- **Rule-specific No-ERC markers (#1699)** — a No-ERC marker can name the ERC rules it silences: select it and tick rules under Suppressed Rules in Properties, and only those rules are silenced at its point while every other rule is still reported there. All Rules (the default, and what every existing marker loads as) silences every rule as before. Each tick is one undo step, the per-sheet check and the project-wide checks honour the list, and copy, cut and paste now carry No-ERC markers with their lists. Sheets without a rule list save exactly as before.
