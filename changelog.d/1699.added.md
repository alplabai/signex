- **Rule-specific No-ERC markers (#1699)** — a No-ERC marker can name the ERC rules it silences: select it and tick rules under Suppressed Rules in Properties, and only those rules are silenced at its point while every other rule is still reported there. All Rules (the default, and what every existing marker loads as) silences every rule as before. Each tick is one undo step, the per-sheet check and the project-wide checks honour the list, and copy, cut and paste now carry No-ERC markers with their lists. Sheets without a rule list save exactly as before; a sheet with one is saved as `snxsch/1.2`, which an older Signex opens read-only rather than dropping the list on its next save.
- **No-ERC rule lists from scripts and agents (#1699)** — `place_no_erc` takes an optional `rules` operand (comma-separated ERC rule ids), and the new `edit_no_erc_rules id [rules]` sets the list of a placed marker in one undo step; left out or empty means every rule. Rule lists are saved sorted, so a sheet does not change with the order rules were picked in.
