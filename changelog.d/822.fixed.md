- **External `.snxlib` row edits now show up (#531)** — a library edited by another window, a `git pull` or a text editor is re-read when it changes on disk, so new rows and tables appear on the next refresh instead of staying hidden until restart. An in-app edit is applied on top of the external change instead of overwriting it, and an unreadable file keeps the last good view, refuses writes and logs a warning.
