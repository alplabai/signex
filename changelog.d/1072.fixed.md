- **A stale library row can no longer overwrite someone else's save (#115, #1072)** — saving or deleting a database-library row now names the revision it was read at (`If-Match`), and the server refuses the write with 409 and a "changed by someone else" message when the row has moved on, instead of silently replacing it. Row `PUT`/`DELETE` now require `If-Match` (an older client gets 428), so client and server must be upgraded together. A Component Preview or Edit Component modal whose save was refused offers **Reload from server**, which asks before it drops your edits; an unedited preview of a row that another surface just saved reloads itself, while an edited one keeps its draft and is refused on save. The unused advisory-lock endpoints are removed from the library server.
