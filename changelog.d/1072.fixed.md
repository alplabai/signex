- **A stale library row can no longer overwrite someone else's save (#115, #1072)** — saving or deleting a database-library row now names the revision it was read at (`If-Match`), and the server refuses the write with 409 and a "changed by someone else" message when the row has moved on, instead of silently replacing it. Row `PUT`/`DELETE` now require `If-Match` (an older client gets 428), so client and server must be upgraded together. Every editor open on a row also follows its saves, so saving from the browser no longer makes the preview's next save look stale.
