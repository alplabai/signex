- **Smart Paste from the command line (#2665)** — `smart_paste` takes the Smart Paste dialog's choices as operands (`at`, `delta`, `copies`, `designators`, `nets`, `net_pattern`, `net_start`): a CLI run pastes the copy once at an offset or as an array, numbered and named as the dialog does, as one undo step, and answers with the designators and net names each copy got. A rewritten net name already in use, or an unreadable project sheet, stops it as it stops the dialog.
