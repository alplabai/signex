- **Update PCB from schematic and New PCB (#1312)** — Design ▸ Update PCB Document `<board>` on a schematic, Design ▸ Import Changes From `<project>` on a board, the Projects tree's project row and the command palette (`update_pcb_from_schematic`) open the Update PCB dialog: every footprint to add, remove or change, each designator, value, link, net and pad net, grouped with a box per group, with the rows that cannot run marked and why (a missing footprint, a part to annotate, with Annotate... and Cross Probe links). Execute applies the ticked rows as one undo step; Validate tries them first, Report... saves the list as text, and Refresh re-reads the schematic and keeps your ticks. A board closed with unsaved edits or opened read-only is listed but not changed. File ▸ New ▸ PCB and Projects ▸ Add New ▸ PCB (`new_pcb_document`) give the project its board from the project's setup (layer count and rules); it is not written until you save. Headless and CLI runs use `update_pcb_from_schematic apply=true`.
