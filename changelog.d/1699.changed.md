- **Sheet symbol, drawing, directive and multi-selection Properties follow one layout** — a sheet symbol shows a line-art drawing of itself (size, entries with their directions, line width), then Location, Properties (Name, File with Browse…, Open Sheet), Style (Border, Fill, Line Width; an empty Line Width is the default) and a read-only Entries list; when its file is not in the project folder, an error banner offers Create Sheet… and Browse…. A drawing shape shows a line-art drawing with its dimensions instead of the old preview, then Location, Properties and an Appearance section where Fill (None / Outline / Solid) and Placement are segmented controls. Blanket and No-ERC directives share one Suppressed rules section: All rules comes first, and while it is on the rule filter and every rule box are disabled with a caption saying why. A multi-selection shows kind chips (All / Parts / Labels / Wires) that only choose which sections the panel shows, one section per kind with its count, wire width presets, a footer counting each kind, and a "Nothing to edit together" card listing what is selected.
