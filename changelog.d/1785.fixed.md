- **Parameter Manager table (#1783)** — clearing a cell now keeps the parameter with an empty value instead of deleting its column, and a typed cell is one undo step committed on Enter, on moving to another cell, or on closing, rather than one per keystroke. Esc closes the manager and drops an uncommitted cell. Deleting a parameter is an explicit column button (undoable), and the table gains an "Add column" box and a row filter.
