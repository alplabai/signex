- **A default wire is as wide as the pin it ends on (#1946)** — a wire with no stored width now draws, and exports to SVG and PDF, at 0.254 mm (10 mil), the width of the stock symbols' pins, instead of the 0.15 mm floor. The canvas, hit-test and exports take the width from one function, so a net class width of 0 or a width under 0.15 mm now reads the same everywhere. Bus entries draw at the wire weight, and exported buses at the canvas's 0.45 mm so they still stand apart from wires. Wires with an explicit or net-class width are unchanged; no file is rewritten.
