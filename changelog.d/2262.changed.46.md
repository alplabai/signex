- **Enable Version Control names the first commit and asks about every save (#2262)** — the dialog lists the files in a bordered list with a file-type icon, the path and its kind, counts the ticked rows and offers Select all. A new First commit message field (prefilled "Initial version of" and the project's or library's name) is the subject of the repository's first commit instead of "chore: enable version control"; Enable waits while it is blank. For a project, a Commit every save switch (on by default) decides whether every later save is committed; turned off, the repository is created and saves are not committed until the Project tab's switch is turned on. The intro now says in plain words what the dialog does.
