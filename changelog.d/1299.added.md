- **Export Jobs and PNG pages (#1299)** — an Export Job (`.snxout`, format `snxout/1`) lists a project's outputs: schematic PDF and PNG pages at a chosen resolution, BOM and netlist, and the board's Gerber, NC drill, pick and place, IPC-D-356, IPC-2581, ODB++, STEP model and assembly drawings. It opens as a document tab (View ▸ Panels ▸ Export Jobs, or a `.snxout` in Projects) with run profiles (the ticked outputs, one variant, the folder, a zip, folders by group, a release folder), automation (run on save, keep outputs up to date, before close), a run that goes Validate, Generate, Package and Summary as a flow, and a history kept in the file. The summary's View in Gerber Viewer opens exactly the files a run wrote. `run_output_job` runs a profile, every enabled output or one by name from the palette or headless with `signex-cli`, and two runs write the same files; every action of the tab is a command. `export_sheet_png` writes a schematic's pages as PNG images. The rules are in `docs/OUTPUT_JOBS.md`.
