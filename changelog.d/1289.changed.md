- **Grouped ERC rule editor (#1289)** — the rule editor in the ERC dialog and in Preferences ▸ Rule Profiles lists the rules under Pins, Nets, Labels, Buses, Hierarchy and Parts, each with an E / W / I / Off control filled in its severity colour (Pin type conflict stays On / Off). A dot marks a rule that differs from the shipped profile, and "Changed only" with a count and a "Filter rules" field narrow the list. The pin connection matrix shows only its lower triangle as tinted severity chips, rings the cells that differ from the shipped profile, and has a legend.
