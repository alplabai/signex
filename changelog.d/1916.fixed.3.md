- **Nested libraries (#1916)** — a file in a library nested inside another library's folder now belongs to the inner library for the symbol delete warning, picker filtering, close prompts and draft saves (write, cascade and refresh), and Browse in the primitive picker binds only a file the open library actually holds (in its `symbols/`, `footprints/` or `sims/` folder). A symbol outside every open library is offered as a copy or "open library"; a footprint or simulation file outside it is refused with a message naming that kind's folder, in the picker and in Messages. Browse of a footprint or simulation file in an open library now works.
