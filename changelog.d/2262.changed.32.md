- **Hover and error cards in the Graphite style (#2262)** — the symbol hover card is titled by the designator over Value, Footprint and Library, and the net card shows a pin count beside the net name; both float like the menus. The error card has a header with a red or amber mark and a close button, keeps the path and system error in their own block with a Copy button, and File Changed on Disk now offers Save As… as its safe default, so you can keep both your edits and the changed file; picking the changed file itself in that dialog writes nothing and brings the card back. File ▸ Save As onto the file a sheet is open from now checks it like Save: a file another program changed is kept and the card comes back, while a file that was deleted is written again as before. When the sheet's folder itself is gone, the Folder Missing on Disk card now explains it instead of a save error.
