- **View ▸ Cycle Grid Size and Design ▸ Electrical Rules Check run their command ids (#1991)** — Cycle Grid Size now runs `next_grid` (it still steps the snap grid, and is no longer greyed in a symbol editor), and Electrical Rules Check runs the new `open_erc_dialog` command, which opens the ERC dialog. F8 (`run_erc`) still runs ERC at once. The Electrical Rules Check row no longer shows F8, and the Cycle Grid Size row no longer shows G (in the Altium profile G opens the footprint grid picker), since a row shows only the shortcut of the command it runs.
