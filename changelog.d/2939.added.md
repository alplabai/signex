- **Component height and 3D body clearance rules (#2939)** — a `component` rule limits how tall a part's 3D body stands (`height <= 6mm`, optionally for one side) and how close two parts' bodies on one side come in 3D (`clearance >= 0.25mm`), so a short part under a raised body is found. The body comes from the library model, the library 3D Body or the part's stored Height. Both run in Run DRC and `check_drc`, are set on the Rules tab's Placement domain, and `query_part_heights document=<board>` answers each part's height and where it came from.
