- **Breaking: `.snxpcb` boards saved by this version are format `snxpcb/1.4` (#2242)** — pads may carry the `trapezoid_delta` and `custom_outline` columns. A trapezoid with no delta, a delta set on both axes or one too wide for its pad, or a custom outline with fewer than 3 corners, no area or crossing edges, fails to load naming the field and value, and is refused on save. A 1.3 build opens a 1.4 board read-only, and refuses one that holds a trapezoid or custom pad.
- **Breaking: footprint libraries can hold trapezoid pads (#2242)** — a `.snxfpt` pad may now be written with the shape `trapezoid:<delta x>,<delta y>`, and a sketch pad attribute may be a `Trapezoid` with delta expressions. Every footprint file this version saves is format `snxfpt/1.1`, so an earlier build refuses it with an unsupported format error; this version reads `snxfpt/1` and `snxfpt/1.1` and refuses a newer token by name. A trapezoid whose delta is too wide for the pad's size, or for any per-layer size on the board, is refused: the footprint editor does not take such a size or delta, a sketch bake warns, placing the footprint on a board names the pad, and a hand-edited file holding one opens with a Messages warning naming the footprint and the pad.
