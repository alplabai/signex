- **Alternate part and variant value from the canvas (#3038)** — right-click a part ▸ In variant ▸ Alternate… opens a picker that lists the part's library alternates, then a search over the project libraries, and compares the picked part's pins and footprint with the placed one; Edit value for this variant… opens a popover on the part with the Base value, the variant's value and Reset to base. On a channel tab either applies to all channels or to this channel only. Each is one undo step. The canvas marks a part with an alternate `alt` and a value of its own `Δ`, each naming the variant and the Base value on hover, and the Variant Manager cell shows the alternate's part number. `project_set_variant_alternate` and `project_set_variant_override` take `scope=channels` to set every channel's copy at once.
