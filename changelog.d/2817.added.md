- **Symbol pins from the CLI and agents (#2817)** — `edit_symbol_pins document=<.snxsym>` does what the Pin table tab's bulk edit, Delete selected and Paste rows do: `pins` sets fields by pin number or removes a pin, `paste` reads datasheet rows with a column map and a paste mode, as one undo step answered with the pins as JSON; `dry_run=true` shows the result without changing the symbol. `undo document=<.snxsym>` now steps a symbol file too.
