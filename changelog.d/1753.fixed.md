- **Annotate and Reset follow-ups (#1753)** — Saving an open sheet while a run reads is no longer refused (a History restore or Replace write still is); the run cancels instead. The Annotate dialog disables Run, Reset and Re-prefix and shows "Running" while a run is going. Reset & Renumber refuses the whole run, with a clear message, when a sheet would be skipped, instead of renumbering around it into duplicates, and the same goes for a sheet that cannot be read. The golden fixture now covers locked parts, a child placed twice and parked engines.
