- **DigiKey OAuth honours Cancel (#834)** — cancelling the Connect flow now stores no refresh token even if the browser callback or the token exchange was already under way, and a token stored by a cancel that lost the race is removed again; the cancellation is reported in the Messages panel. The callback connection is blocking with a 10 s timeout, so it no longer fails spuriously on Windows, and an idle speculative connection is skipped instead of ending the flow.
