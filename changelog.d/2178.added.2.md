- **One agent edit across several sheets (#2178)** — one `apply_edits` call may now edit several sheets of the same project: an edit names its sheet in `document`, and `expect_revisions` holds the revision of each sheet but the call's own. The call is all or nothing across the sheets, one undo group on every sheet (one Ctrl+Z, or one `revert`, takes it back on all of them), and is journaled as one line per sheet. A call that names one sheet answers as before. Project-wide data (net classes, annotation) is still not an edit.
