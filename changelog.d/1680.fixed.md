- **Add Parameter in the Edit Component Details dialog offers the class template's missing slots (#1680)** — A "Template parameters" row lists each slot the component does not hold yet, and picking one adds it in the slot's own kind: a measurement in the slot's unit (fixed, with the slot's sign rules from the first edit), a number or a text. Saving a slot row left empty is refused instead of storing a placeholder zero. "+ Add Parameter" still adds a free-form parameter.
