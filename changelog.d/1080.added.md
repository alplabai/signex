- **Rename a project variable in place (#1080)** — in the Project tab's Parameters, type over a variable's name and press Enter: the value keeps its new name as one undo step. A blank name, a name that is not letters, digits and `_`, a title-block field or a name already used is refused with the reason. Sheet text that uses the old name keeps it, and a warning under the row says so before Enter. A filter above the list finds a row by its name or value, and the caption counts the title-block fields and variables.
