- **One format-version rule for every Signex file (#2207)** — schematics, boards, projects, libraries, footprint, symbol and simulation files now check their format token through one shared rule. A file written by a newer Signex is refused with a message that names the file and its version (a newer schematic or board minor still opens read-only, with saving refused), a file with a garbled token or, except for projects, no token is refused instead of being read as some version, and a simulation file always saves with the current token. Which files open is unchanged; the error messages read the same way for every kind of file. The rules are in `docs/FORMAT_VERSIONS.md`.
