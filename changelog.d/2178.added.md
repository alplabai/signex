- **Agents edit a sheet as one labelled undo step (#2178)** — `apply_edits` runs a list of catalog edit commands (the placements, `color_net`, `clear_all_net_colors`) on one named sheet, all or nothing, as a single undo entry labelled "Agent: <summary>", and refuses with the reason, changing nothing, if the sheet moved on since the `revision` `read_document` reported. A person's active tab, selection, tool, drag and typing are untouched while it runs, and the sheet redraws live. `revert` takes the agent's own step back, only while it is the newest step of that sheet; an agent cannot undo a person's step. `signex-cli` lists both commands under the `edit` capability and checks every edit like a command of its own.
