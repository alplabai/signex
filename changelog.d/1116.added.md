- **Images on a sheet as project assets (#1116)** — Place ▸ Graphics ▸ Graphic… places a PNG, JPEG, GIF or SVG file: it lands on the cursor and one click places it. The sheet stores the file's path in the project and its content hash, never the picture; a file picked from outside the project is copied into `assets/images/` when the sheet is saved. A missing or changed file keeps its place and draws a placeholder, and Messages names it once. Files over 32 MiB or 64 Mpx, and SVG files that refer to anything outside themselves, are refused. `place_graphic path=<file> at=x,y [width=<mm>]` does the same from the CLI or an agent and answers with the image as JSON.
