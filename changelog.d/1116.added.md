- **Images on a sheet as project assets (#1116)** — Place ▸ Graphics ▸ Graphic… opens the Place Image dialog: the project's images as thumbnails with a preview, the file facts and a Width field; Add image file… takes a PNG, JPEG, GIF or SVG from anywhere. The image lands on the cursor and one click places it. The sheet stores the file's path in the project and its content hash, never the picture; a file picked from outside the project is copied into `assets/images/` when the sheet is saved. Properties ▸ Image edits the file (Replace…, Show in folder), the size (Keep aspect ratio, Scale, W / H, Reset to file size) and the look (Opacity, Placement, Border); eight handles resize the image. A missing or changed file keeps its place, draws a placeholder and shows a banner with Relink…, which points every image naming the old file at a new one. The Projects tree lists `assets/images/` with use counts and missing marks, the status bar counts missing assets, and the ERC rule `image_file_missing` reports them. PDF export embeds the pictures (SVG as vectors). Files over 32 MiB or 64 Mpx, and SVG files that refer to anything outside themselves, are refused. `place_graphic`, `set_image`, `relink_image`, `show_image_in_folder` and `list_image_assets` do the same from the CLI or an agent and answer with JSON.
