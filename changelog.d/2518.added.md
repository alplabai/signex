- **Sketch info bar (#2518)** — in sketch mode, the footprint and board sketch show what is sketched, the plane and the grid step, with a **Parameters** button, at the canvas's top right.
- **Parameters table (#2518)** — Name, Expression, Value, Unit and Used by for every sketch parameter; Add parameter; typing re-solves on each keystroke, and a row in error keeps the last good solve and shows its message; typing a letter offers the parameter names with their values.
- **Rename and delete parameters (#2518)** — a row's ⋯ menu has Rename…, which renames every reference (whole names only), and Delete; deleting a used parameter asks first, naming its uses, and Replace with value puts its value in each use, as one undo step.
- **Make parameter (#2518)** — a dimension's value becomes a named parameter the dimension reads, as one undo step, and the table opens on it.
