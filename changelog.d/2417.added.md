- **Net Classes and SCH Filter panels (#2417)** — the Net Classes panel now opens the project's net-class editor on a sheet or a board: a table of classes (name, colour, width, members) above the fields of the selected class, the same editor as Properties, where the class list is now that table too. The SCH Filter panel is the schematic Selection Filter: All / None, your saved presets and a chip per object kind, the chips of the Active Bar's filter dropdown wrapped to the panel. Two new commands set the filter by name from the CLI: `set_selection_filters kinds=wires,net_labels` (or `all` / `none`) and `apply_selection_filter_preset name=<preset>`.
