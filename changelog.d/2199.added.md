- **`query_pins` lists a part's pins (#2199)** — the new read-only query `query_pins document=<sheet> designator=U1` answers with each pin's number, name, electrical type, hidden flag, unit and tip position in mm, for every placed unit of that part, from the command line and from an agent connection. An unknown or ambiguous designator, or a document that is not a loaded schematic, is refused with the reason. Nothing in the editor changes.
