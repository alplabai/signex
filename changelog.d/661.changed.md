- **Net colours are steps of the sheet's undo history (#661)** — undoing a net colour back to the saved colours leaves the sheet clean (it used to stay unsaved until the next save); colour steps share the undo depth with every other edit and fall off the history oldest first; and a colour step on a member sheet now blocks a project-wide undo (annotate, Replace) like any later edit on that sheet.
- **Colour a net and clear all net colours from a command (#661)** — `color_net` (`at`, `color`, optional `path`) and `clear_all_net_colors` (optional `path`) run the same edit as the pen click and the Active Bar button, with the undo step and dirty state a click makes; a command that declares operands but has no operand handler is refused instead of run without them.
- **Exports draw the net colours you see (#661)** — SVG and PDF export now use the sheet's live net colours; before they drew the colours the sheet had when it was opened.
- **Net colour and net-class pick undo in true time order (#661)** — when a colour and a net-class pick were made on one sheet, Ctrl+Z reverts the newer first; before, the colour always went first.
- **A headless command that needs operands is refused without them (#661)** — `color_net` and the placement commands report why instead of arming a tool or opening a picker and reporting that they ran.
- **Net-class picks are steps of the sheet's undo history (#661)** — a pick sits on the sheet's one timeline in the order you made it, shares the undo depth with every other step, and a pick on a member sheet now blocks a project-wide undo (annotate, Replace) like any later edit there; a pick never makes the sheet unsaved (it changes the project), and undoing it reads the project clean again.
- **Assign a net to a class from a command (#661)** — `assign_net_class` (`net_name`, optional `class`, optional `path`) runs the label picker's assignment with the same undo step and project dirty state; no `class` takes the net out of its listed class. `path` names any open sheet and the command never changes the active tab, focus or panels; headless it is required, and without operands the command is refused with a reason on every surface.
