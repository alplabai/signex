- **Rules tab as a constraint grid (#2530)** — the rule list is now a spreadsheet of every rule type: domain tabs (Clearance, Physical, High speed, Manufacturing, SMT, Mask, Plane, Testpoint, Placement; Signal integrity greyed until the simulation band) with their findings, one collapsible column group per rule type, and the object hierarchy as rows (All, net classes with their nets, copper layers L1 = Top to Ln = Bottom, scoped rules). A cell inherits down the hierarchy: an own value is bold with ↺ to reset it, an inherited one muted, a constraint set's value edged blue with a ⧉ chip on the row, and the tooltip names the source. Find a constraint jumps to its domain and column; Show inherited values and Overridden rows only filter the grid. Under it, the selected cell's live drawing, its rule with violations and Jump, and which value wins and why. Rule sets are called constraint sets. The search box and the All / With violations / Flagged / Off filter are gone.
