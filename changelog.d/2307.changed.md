- **Rule profiles carry DRC rules (#2307)** — Save as profile now writes the project's DRC rules with its ERC rules, Update from profile adopts the profile's DRC rules and lists each DRC change before you confirm, and a changed DRC section in a profile is reported as drift. Projects and profiles without DRC rules keep their exact hashes; a project taken from a profile that already held DRC rules reports the profile as changed once, and Update from profile then records the new hash without changing any rule.
