- **Polygon Manager (#2798)** — Tools ▸ Polygon Manager..., a pour's right-click or the PCB panel's new Polygons mode opens a tab with every polygon pour of the board, grouped by layer in pour order, with Layer, Net and State filters. Clearance, minimum width, island and dead-copper settings are edited in the table or for several ticked pours at once, each edit one undo step; Repour and Shelve work on all, the ticked or one pour.
