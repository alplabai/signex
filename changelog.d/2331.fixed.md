- **Agents can work on a project's board while it is open (#2331)** — a board a project names, open in a tab or closed with unsaved changes, was refused to an agent as "not part of a project open in this app", so `check_drc` and every other `document=` command on it failed until the board was closed. It now belongs to its project as it does while closed: `list_documents`, `document_info` and `resolve` name the project, and the commands run. A board no open project names is still refused.
