- **Open and New run from a `path` operand (#2155)** — `open_document path=<file>` and `new_document path=<dir>/<name>.snxprj` now run on every surface that gives operands, not only through the command-line tool, and do what the menu entry does after its dialog: the same document opens, the same project folder, project file and companion sheet are created, and a refusal reaches the Messages log. `new_document` takes no `overwrite`: it never replaces a project.
