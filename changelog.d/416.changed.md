- **Library tables: a one-row append, update or delete no longer re-parses and re-serialises the whole table (#416)** — the edit scans the file for record boundaries, copies untouched rows through as raw bytes and encodes only the changed record, still via the atomic temp-file write. At 10k rows an edit drops from about 79 ms to 18 ms and at 50k from about 360 ms to 80 ms; settings files are small enough that they were left alone.
