- **Library row edits do less redundant work on large libraries (#416)** — the git commit of a saved `.snxlib` now reads and hashes the file once instead of twice, and the table writer no longer copies every cell or re-looks-up each row's id on every sort comparison. On a 50k-row library the commit step drops from about 280 ms to 160 ms and serialising the table from about 230 ms to 135 ms. An edit still rewrites the whole file through the atomic temp-file write, is still read back and compared before it replaces the old file, and an edit from a stale copy is still refused.
