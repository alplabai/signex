- **Annotation numbering by page (#1292)** — a project can number its designators per page: page × 100 (R101, R102 on page 1, R201 on page 2) or page × 1000, chosen with `project_set_annotate_numbering` and stored in the project. The Annotate preview and the sheets table's Start column show the numbers each page gets; a run refuses, changing nothing, when two pages share a number or a page's block is full. Continuous numbering stays the default.
