- **Dock panels and commands in an undocked window act on its document (#1966, partly)** — the panels in an undocked window (Properties first) now show and edit that window's sheet, selection and paper size instead of the main window's, and their edits change only that sheet. Shortcuts and menu commands other than Save, Print, Undo and Close Document run on the sheet the window shows, except those that open or step to another sheet (next/previous sheet, up hierarchy, net-partner jumps), which stay on the main window; so do the Projects, Navigator, History restore and ERC focus actions. A Components row dragged from such a window drops onto its sheet. Still open: the tab-strip and project-tree menus, the Components row menu, Find, and the Components drag ghost in that window.
