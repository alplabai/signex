- **Commands and dock panels in an undocked window act on its document (#1966, partly)** — shortcuts and context-menu commands other than Save, Print, Undo and Close Document ran on the main window's active sheet; they now run on the sheet the window shows. The dock panels in an undocked window (Properties first) now show and edit that window's sheet, selection and paper size instead of the main window's, and their edits change only that sheet. Opening a sheet from the Projects or Navigator panel still runs on the main window. The tab-strip menu in an undocked window is still open, as is the Components drag ghost there (the drop itself lands on the window's sheet).
