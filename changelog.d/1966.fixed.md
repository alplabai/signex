- **Dock panels and commands in an undocked window act on its document (#1966, partly)** — the panels in an undocked window (Properties first) now show and edit that window's sheet, selection and paper size instead of the main window's, and their edits change only that sheet. That includes the sheet-symbol Name and File fields, the colour pickers, stroke width, Update from library, placed-part actions and the pre-placement form; Edit Symbol opens the symbol tab on the main window, and the Net Classes section shows the project-wide table the main window edits. Edit, selection, tool, Active Bar, zoom, AutoFocus, Esc and Bring to Front / Send to Back shortcuts and menu commands typed in the window run on the sheet it shows, and a command is enabled by that window's own selection. Everything else stays on the main window: Save, Print, Undo and Close Document act on the window's document through their own paths, and sheet stepping, project opens, Find, Annotate, ERC, export and the Projects, Navigator row-click, History restore and ERC focus actions run on the main window. A sheet switch inside a window is refused with a Messages line, and a descent through a sheet symbol is queued to the main window. A Components row dropped from, or placed from the row menu of, such a window arms on and lands in that window's sheet. Title-block and paper-edge drafts typed in a window are merged per sheet and field into the main window's when it reattaches. Still open: the tab-strip and project-tree menus, Find, and the Components drag ghost in that window.
