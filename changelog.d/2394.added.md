- **Layer sets and a full layer tab menu under the board (#2394)** — A layer set button at the left end of the layer tabs names the set the tabs list and opens All Layers, Signal Layers, Plane Layers, Non-signal Layers, Mechanical Layers, your saved sets, Save current as set... and Manage sets...; picking a set shows only its layers on the board and in the tabs, and an active layer outside it moves into it. Right-clicking a tab now also offers Highlight (every other layer dimmed), Hide layers ▸ and Show layers ▸ per kind (signal, plane, overlay, mask, paste, mechanical, all), Short, Medium and Long tab names with Show layer numbers, and Flip board view (the board seen from below: mirrored, bottom copper drawn over top copper). Layer stack..., Drill symbols... and Layer drawing order... are listed greyed with the reason until those editors exist. Saved sets and tab names are kept per user; the flip is a view setting and never changes the board. Every action is also a command with operands for scripts and agents, and Flip Board View and Show Layer Numbers are in the View menu.
