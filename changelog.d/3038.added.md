- **Variant edits for scripts and agents (#3038)** — new commands `project_set_variant_fit`, `project_set_variant_alternate`, `project_set_variant_override` and `project_duplicate_variant` set a part's fit, its alternate part, a parameter value and a copy of a variant from signex-cli and the agent channel, each as one undo step with the same result as the Variant Manager. Set as default is `project_set_default_variant`.
