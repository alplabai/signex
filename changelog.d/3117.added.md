- **Import Library dialog (#3117, #3118, #3119, #3120)** — File ▸ Import ▸ Library… turns a library made in another tool into a Signex library through an installed library converter, in three steps: pick the files (or a database link file) and see which converter reads them, with name, folder, mount scope and 3D models; preview what will be written, approximated, dropped or skipped without writing anything; then import, with the current phase, item and progress. Cancel stops after the current item and removes what was written. When no converter is installed, the dialog says how to install one.
