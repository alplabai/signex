- **One pin electrical type for the symbol editor, `.snxsym` and the schematic (#2108)** — the library no longer has its own 10-variant pin type that was folded onto the schematic's 14; the symbol editor's Electrical dropdown now offers all 14 (new rows: Power Output, Ground, Differential, Clock; the old "Power" row is labelled "Power Input"). Existing `.snxsym` files read exactly as before (`Power` stays a power input) and re-save byte-identical; a symbol using one of the four new types writes a new token that a build from before this change refuses to load.
