- **Board Component Properties (#2354)** — with components selected on a board, the Properties panel shows a Component view: a header naming the selection with a row search and General / Parameters tabs, then Location (X, Y, Rotation, Locked), Properties (Layer, Designator and Comment with show/hide eyes, Area, Description), Footprint (name, library), Swapping Options and Schematic Reference Information (hierarchical path). Editing X or Y moves the components, Rotation turns them, picking the other layer flips them, an eye hides or shows the text, and the lock stops moves, turns, flips and edits; each is one undo step. Several components show the values they share and leave a differing one blank. The Parameters tab edits the shared parameters. Rows the board does not store yet (Type, Design Item ID, Source, Height, 3D Body Opacity, the primitive and string locks, swapping, the footprint picker, Channel Offset, the schematic designator) are shown disabled with a tooltip saying why.
