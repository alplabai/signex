- **Schematic text scales with the drawing at every zoom (#2022)** — sheet text is its true size (1.27 mm text is 1.27 mm at any zoom), with no minimum or maximum on-screen size set by the schematic. Zoomed out, text no longer outgrows and overlaps the drawing; zoomed in, it no longer stops growing before its geometry does. Text larger than the graphics layer's glyph-atlas limit (1024 pixels) is drawn as vector outlines, so it stays sharp and at true size; text under half a pixel is not drawn, a size above 100 mm in a file is brought back to 100 mm when the sheet opens, with a note in Messages, and notes no longer wrap at the window edge on the GPU. The Component Preview keeps its readable clamp.
