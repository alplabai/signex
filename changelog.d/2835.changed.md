- **Breaking: a project or rule profile with a min slot needs this version or later (#2835)** — a `.snxprj` whose rules name a min slot writes its `rules` section at schema 2, which an older Signex keeps unchanged but does not apply (it runs ERC and DRC with the machine's rules); a `.snxrules` profile naming one is written at schema 3, which an older Signex refuses. Files without a min slot are written as before.
