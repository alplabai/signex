- **Dialog buttons are one family (#2397)** — every dialog footer button now has the same height, corner radius, border width and padding, and changes the same way on hover and press. Cancel and Close get a subtle fill with the standard border, destructive actions such as Discard All a subtle red fill with a red border and label, and the main action such as Save All the accent fill. The Signex mark in a dialog's title bar is now as tall as the title text.
