- **Fabrication outputs from the command line (#2470)** — `signex-cli run` with `--allow export` writes a board's Gerber, Excellon drill, pick-and-place, IPC-D-356, IPC-2581 and ODB++ files (and, when asked, the assembly drawings and the STEP model) into a folder with `fabrication_outputs document=<board> path=<folder>`, exactly as File ▸ Fabrication Outputs' Generate writes them. `kinds` picks the files, and the answer lists each file written with its kind, size and SHA-256.
