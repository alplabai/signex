- **Pin type conflict follow-ups (#919)** — the "Pin type conflict" row in the ERC dialog and Preferences is now on/off only, so it no longer flattens each matrix cell's Error/Warning/Info verdict (the row says so); power flags (`PWR_FLAG`) no longer raise PowerOut x PowerOut conflicts when same-value power symbols merge into one net; and a net with several conflicting pins yields one finding (at the worst cell's severity, listing the other pairs) instead of one per pair.
