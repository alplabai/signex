- **History, Find Next and the command palette in an undocked window follow that window (#2067, #2037)** — The History panel in an undocked window now lists the history of the file that window shows, and Restore there restores that window's file, never the main window's; an answer that arrives after the window closed is dropped with a line in the Messages panel. F3 and Shift+F3 pressed in a window search that window's sheet with the last query instead of stepping the Find dialog of another window. The command palette opened in an undocked window has its own text input, so typing filters its rows and Enter runs the highlighted one.
