- **Breaking: footprint libraries with sketch links are format `snxfpt/1.2` (#2518)** — a footprint file whose sketch holds a reference dimension, a pattern source or mirror, or a per-instance pad override is saved as `snxfpt/1.2`, which an earlier build refuses by name instead of dropping the links on save. Files without them are still saved as `snxfpt/1.1`, unchanged.
