- **Placed ICs show their pin numbers and pin names (#1961)** — a symbol on the sheet used to draw only its body and bare pin lines. Each pin now shows its number beside the pin line and its name inside the body, following the per-pin and symbol-level show-numbers / show-names settings; SVG and PDF export place the text the same way. Pin text turns with a vertical or rotated pin and every vertical pin reads bottom-to-top, with the number on the same side; the symbol editor and the sheet now lay pin text out by the same rule.
