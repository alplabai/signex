- **New Project setup dialog (#2232)** — File > New Project, the Start screen button, the command palette, Ctrl+N and New Project... in the Projects panel's empty-area menu open one dialog: project name, location with Browse, a `Create "<name>" folder` checkbox, profile cards (Hobby 2-layer, Standard 4-layer, HDI 6-layer, Custom), a folded Customize section (generic Standard, Advanced and HDI fab rule templates, Import rules from a TOML file, copper layers 1 to 32, clearance, track, via and drill, sheet size, title block, designator standard) and a stack-up preview. The choices are stored in the new `.snxprj` as the project's defaults, and sheets added later start from them. Project Options gets a Project setup section to edit them later, with the same cards and fields. Create is off, with the reason shown, when the target already exists or the folder is not empty. The command `new_project_with_profile` does the same without the dialog. Nothing is written before Create. See `docs/PROJECT_SETUP.md`.
