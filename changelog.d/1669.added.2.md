- **⌥I adds a vertex and ⇧Tab cycles the drag wiring mode on macOS (#1669)** — in the Altium profile on macOS, `Option+I` runs add vertex while drawing (else Copy Attributes), since a Mac keyboard has no Insert key, and `Shift+Tab` cycles the drag wiring mode, since macOS takes `Ctrl+Space` for the input source; Windows and Linux keep `Insert` and `Ctrl+Space`.
