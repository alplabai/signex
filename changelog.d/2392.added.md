- **Grouped tool buttons on the board Active Bar (#2392)** — the board's Active Bar now has group buttons like the sheet's: Components, Route, Via / Pad, Copper areas, Copper drawing, Dimensions and Text. A button runs its group's last-used tool, and a right-click opens the group's other tools, with tools that are not built yet greyed and the reason in the tooltip. The last tool of each group is remembered across sessions, whichever way the tool was armed (bar, Place menu, key or palette).
