- **Five more schematic shortcuts work (#1668, #1669, #1671)** — Center on cursor (F4 in the Classic profile) recentres the view on the cursor like Center View At Cursor; Refresh/redraw (End / F5) redraws the active canvas from the model; Undo last segment while drawing (Classic Backspace) ends a wire draw like Remove Last Vertex; Select / expand connection (Classic Mod+4) grows the selected wire, bus, junction or label to its net like Select ▸ Connection; and Select node / connection item (Classic Alt+3) selects the one wire, bus, bus entry, junction or label under the cursor, or says in Messages that there is none. Before, these keys only said the command was not available yet.
