- **Side panels can be dragged wider (#2347)** — a left or right dock panel is no longer capped at 500 px: it grows until the canvas keeps a minimum width beside the other panel. A smaller window, or the other panel opening, takes width back from the wider panel first, so the panel you did not widen keeps its width. Every property row keeps a fixed label column, so the extra width goes to the fields, and a panel never gets so narrow that a field has no room.
