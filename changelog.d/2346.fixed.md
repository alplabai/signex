- **The Home screen navigation folds to an icon strip in a narrow window (#2346)** — when the area beside the navigation would be under about 480 px, the navigation becomes a column of icons, each showing its label (and the Open shortcut, or "Coming soon" for Parts search) on hover, and the main column takes the freed room. The strip scrolls in a window too short for it, and a wider window brings the full navigation back. The full navigation's width is now derived from the base text size.
