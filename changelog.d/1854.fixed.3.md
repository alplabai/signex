- **Undo in the Component editor, and it clears the unsaved mark when it returns to the saved row (#1854)** — Ctrl+Z / Ctrl+Y in a Component editor tab now step its row edits, and undoing every edit since the last save or open shows the row as saved again; redo shows it unsaved again. A row stays unsaved while its write is running or after a failed save, after a simulation-model edit or a bound primitive (those cannot be undone), and while a half-typed value waits in a field. Reloading the row starts a fresh history.
