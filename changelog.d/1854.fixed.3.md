- **Undo in the Component editor, and it clears the unsaved mark when it returns to the saved row (#1854)** — Ctrl+Z / Ctrl+Y in a Component editor tab now step its row edits, and undoing every edit since the last save or open shows the row as saved again; redo shows it unsaved again. A row stays unsaved while its write is running or after a failed save, after a simulation-model edit, and when an inline edit changes a primitive reference (those cannot be undone; undo does not cross a primitive bound from the picker either). A change the library made behind a dirty row also keeps it unsaved, and while a half-typed value waits in a field. Reloading the row starts a fresh history.
