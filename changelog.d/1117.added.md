- **New projects get a managed `.gitignore` (#1117)** — New Project and Enable Version Control keep a marked block of Signex-generated leftovers (atomic-write temp files, library write-lock files, OS clutter) in the project `.gitignore` and, with LFS, in `.gitattributes`. Your own lines are never touched; links, read-only files and unbalanced markers are refused and logged to Messages. If the project folder is the root of an existing repository, the block lands in that repository's top-level `.gitignore`.
