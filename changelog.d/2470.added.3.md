- **Route a board from the command line (#2470)** — `place_board_route`, `place_board_track`, `place_board_quick_route`, `place_board_diff_pair`, `place_board_multi_route` and `place_board_via` take operands (the board, the start and end as points or pads, the corners between, the layer, width, net or nets, the corner rule and the route mode) and run headless through the same interactive router as their clicks, one undo step each, answering with the tracks and vias made as JSON; `dry_run=true` answers without changing the board. There is no autorouter: each command routes the nets it names. See `docs/CLI.md`, "Routing a board".
