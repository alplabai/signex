- **Agent journals (#2253)** — what an agent changes and who connected is now kept in the project, in `.signex/agent-edits.jsonl` (every document-changing agent command, with its operands, revisions, undo group and outcome) and `.signex/agent-access.jsonl` (connections accepted, refused and closed, with the rights they were given). Project setup gets an "Agent journals" group: keep the journals in git (on), summarise agent changes in the commit message (stored; the commit body follows later), and how many lines each journal keeps (10,000). `signex-cli agent-log <project>` prints the table; a headless run writes journals only with `--save`.
