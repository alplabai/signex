- **Sheets with rotated text no longer stall the canvas (#2128)** — rotated labels and notes are drawn after the upright ones, so iced no longer opens a layer per rotated text on every frame; on a large test sheet an idle frame went from 62 ms to 2 ms and memory from 3.3 GB to 0.6 GB. Where a rotated text overlaps an upright one it now draws on top, as the GPU path already did.
