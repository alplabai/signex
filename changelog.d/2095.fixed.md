- **Shortcuts work on Russian, Greek and other non-Latin layouts (#2095)** — when a non-Latin letter key matches no binding, it is read at its US-layout position, so the W key places a wire on a Russian keyboard just as it does on a US one. Ctrl+Z, Ctrl+C and the other chords already did this; now bare and Shift letters do too, and the symbol and footprint editor canvases read Ctrl+A, Ctrl+Z, Ctrl+Y, Ctrl+X/C/V and X the same way. A binding on the layout's own letter still wins, and Latin layouts (Dvorak, AZERTY, accented letters) are unchanged. A key that types an ASCII character is not remapped: on a Greek keyboard the Q key types `;`, so Q and Ctrl+Q do not reach a Q binding there.
