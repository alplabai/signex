- **Allow agent connections (#1924)** — Preferences > Editing has a new "Allow agent connections" switch, off by default. When on, the running Signex listens on a socket only you can open (a Unix socket in your runtime folder, a named pipe on Windows; never a network port) and runs requests from an agent as you, one at a time with your own edits. An agent names its document, uses the same commands as the headless CLI and never changes your tab, selection, tool or panels. Every request, with the client's process id, is listed in Messages. Turning the switch off closes the socket and drops the connections; with it off nothing changes.
