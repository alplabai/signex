- **Anti-aliasing is a preference, on by default (#2022)** — Preferences > Appearance > Rendering has an "Anti-aliasing (MSAA 4x)" switch that smooths the edges of canvas shapes such as the vector outlines of very large text and filled polygons; it applies after a restart, and an older settings file without it reads as on. Grid lines and dots now snap to whole device pixels like wires do, so the grid stays crisp.
