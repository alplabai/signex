- **Reused child sheets annotate per placement (#1835)** — Reset & Renumber now starts from 1 instead of counting the designators it is about to clear. A sheet file placed by more than one sheet symbol is numbered per placement and the designators are written as `Symbol.instances` entries (undoable on open sheets), so the netlist export no longer refuses it. The Create Sheet dialog no longer offers "Open it" for a file another sheet symbol already points at, and names that symbol.
