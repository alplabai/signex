- **A symbol saved by Add New ▸ Symbol Library can be bound to a component and edited (#1841)** — the symbol picker lists the project's own `.snxsym` files under "Not in a library" (Browse filesystem… accepts any `.snxsym`, whatever its name), and choosing one asks to copy it into the row's library, binds the copy and leaves the original file untouched; the copy keeps its uuid unless the library already has it. Edit Symbol and the Component Preview's Open Symbol Editor find the file the library lists the symbol in, so a symbol file named by its author opens.
