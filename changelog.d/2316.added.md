- **Rotatable board view (#2316)** — the PCB view turns on screen to make layout and routing easier: View ▸ Rotate View 90° Clockwise, 90° Counter-Clockwise, 180° and Reset View Rotation, the same rows in the command palette, a Rotate View button on the PCB Active Bar, and a View readout in the status bar that opens a field for any angle. Picking, box select, footprint drags, snapping, the grid, culling and Fit follow the turned view on the CPU and GPU paths. The turn is view state like pan and zoom: no undo step, no dirty mark; a board opened into a tab starts upright. Agents pass `view_rotate degrees=<angle>` and read the angle from `document_info` (`view_rotation_deg`).
