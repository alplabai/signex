- **Board shape, keepout and arrange from a selection (#2409)** — Tools ▸ Board Shape from Selection makes selected lines that close a loop the board outline; Tools ▸ Keepout from Selection turns a selected copper area, or closed lines, into a keepout on its layer; Tools ▸ Arrange in Box packs the selected components inside a box drawn with two clicks, without overlap. All three are on the board right-click menu too, each one undo step, and run from an agent or the CLI.
