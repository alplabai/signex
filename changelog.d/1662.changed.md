- **Database tokens saved in plain text now warn once, and can come from the environment (#1363)** — saving a library whose database `auth` is a hand-written token logs one warning per session in the Messages panel; setting `auth` to `${env:NAME}` reads the token from that environment variable when the library connects. The unused per-file TSV table functions (`read_table`, `write_table`, `append_row`, `update_row`, `delete_row`) are removed from `signex-library`.
