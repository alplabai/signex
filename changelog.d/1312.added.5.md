- **Edit a footprint's designator and value on the board; Positional Re-Annotate (#1312)** — With one footprint selected on a board, the Properties panel shows its designator, value and footprint name; type a new designator or value and press Enter to apply it as one undo step. A locked footprint and a read-only board say why they cannot be edited, an empty designator is refused, and a designator another footprint already has is applied with a warning. Tools ▸ Re-Annotate Board... numbers the board's parts by position within each prefix (by X then Y, or by Y then X, with the bottom side after the top side or together with it), lists the renames, and Execute applies them as one undo step; locked footprints keep their designators. The board's right-click menu gains Properties..., and the new `reannotate_board` command is in the command palette and can be given a key. Back Annotate, which carries these changes to the schematic, follows.
