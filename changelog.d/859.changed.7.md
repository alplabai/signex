- **Four more project actions no longer freeze the window (#859)** — opening a child sheet from the canvas (double-click, context menu, Enter) reads and parses the file on a background job and installs the tab, with the placement it was entered through, when it arrives; a missing file still offers to create the sheet. Renaming only the project file (the folder keeps its name) moves it on a background job, holds the old and new path meanwhile, and reports a failed move in the dialog and the Messages panel. The Place Sheet tool lists the `.snxsch` files beside the sheet on a background job before it picks the default name, and a library's Enable Version Control dialog lists its entries the same way (its Enable button waits for them). A descent into a sheet that a rename or delete is moving is now refused with a notice, as the project tree already did.
