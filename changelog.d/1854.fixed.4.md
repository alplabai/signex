- **The Project tab shows saved again when you undo back to the saved project (#1854)** — undoing every General, Parameters, ERC rule and net class edit since the last save or open now clears the project's unsaved mark; redo sets it again. The project stays unsaved while its write is running, after a failed save, and after any change those undo steps do not cover (adding a library, a sheet-list change, a rename): only a save clears those. A history that dropped its oldest steps keeps the project unsaved when no step reaches the saved state.
