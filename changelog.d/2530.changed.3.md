- **Breaking: `rules_list` names a rule's domain by the grid's domain tabs (#2530)** — `domain` is now the domain of the rule's first limit: `clearance`, `physical`, `high_speed`, `manufacturing`, `smt`, `mask`, `plane`, `testpoint` or `placement`. `routing` (track, via) is now `physical`; `holes` is now `manufacturing`; an edge rule moves from `clearance` to `manufacturing`; `assembly` splits into `manufacturing` (silkscreen) and `placement` (courtyard); a mask rule whose first limit is the sliver is `manufacturing`. A script that filters on the old names needs the new ones.
