- **Project fonts (#1178)** — Project Options ▸ Fonts adds .ttf, .otf and .ttc files to the project's `assets/fonts/` folder, so the font travels with the project. Each family shows its styles, its embedding permission and a license you record; a font whose license forbids embedding, a file that is not a readable font and a file over 32 MiB are refused with the reason. The project file lists the fonts under a new `fonts` key that older versions keep as it is. The commands `project_add_font`, `project_remove_font` and `project_set_font_license` do the same from the CLI.
