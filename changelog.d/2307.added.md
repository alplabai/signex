- **DRC rule ids and severities (#2307)** — each DRC check is a rule (`builtin::short`, `builtin::clearance`, `builtin::unconnected`, `builtin::keepout`) with a severity: shorts, clearance and keepout violations are errors and unconnected links warnings by default, and a rule profile (`.snxrules`) or a project (`rules.drc` in the `.snxprj`) can set them. What a check finds is unchanged; the severity is not shown yet.
