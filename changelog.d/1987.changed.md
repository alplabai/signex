- **Variable names (#1987)** — a new project parameter or sheet variable name must be letters, digits and `_`, not starting with a digit, so `${NAME}` and expressions can use it; the Project tab's **Custom parameters** heading is now **Variables**. `${name}` finds a variable in any letter case when no exact match exists. A text note or title-block value that starts with `==` now shows one `=` fewer, the escape for a literal `=`.
