- **Library symbol updates keep the sheet copy and its version in step (#950)** — "Update from library", Personal-mode auto-apply and the Team Library Updates dialog now all replace the embedded symbol and stamp the instances' library version together, so an applied update no longer reappears as drift or as a pending update. The Team dialog reads the library's current symbol off the UI thread when you click Apply, as one undo step per shared symbol (never stamping a version over old content) and offers one checkbox per shared symbol, since every instance of it shares one embedded copy. Personal-mode auto-apply at open leaves no undo step. A refused update (a connected pin would vanish) leaves both untouched and says why in the Messages panel. A row re-bound to a different symbol is never stamped onto the old one (the Messages panel names the reference and the row), and the row versions are read together with the symbol when Apply runs, so a row edited since the scan is not stamped stale. A completion for a sheet that was closed and reopened meanwhile is dropped with a Messages line.
