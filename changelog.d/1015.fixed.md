- **Library symbol updates keep the sheet copy and its version in step (#950)** — "Update from library", Personal-mode auto-apply and the Team Library Updates dialog all replace the embedded symbol and stamp the instances' library version together, so an applied update no longer reappears as drift or as a pending update. "Update from library" and the dialog's Apply share one off-thread read: the worker reads the library's current symbol and each instance's row fresh (through the library the row itself lives in, so a row whose symbol is in another library works), one undo step per shared symbol, and offers one checkbox per shared symbol since every instance of it shares one embedded copy. Each instance is decided from its fresh row: a row that binds the symbol is stamped with the version read; a row re-bound to another symbol, a row that is gone and a library that cannot be read each get their own Messages line ("version not stamped", outcome first so the line is never cut short) and the instance keeps its stamp, while the shared copy is refreshed regardless. Personal-mode auto-apply at open leaves no undo step. A refused update (a connected pin would vanish) leaves both untouched and says why in the Messages panel. A completion for a sheet that was closed, reloaded or renamed meanwhile is dropped with a Messages line.
