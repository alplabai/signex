- **Agents may save, close and assign net classes on a named document (#1924)** — over the agent connection, `save_document` writes the named document only, `close_active_document` closes the named document's tab (a document with unsaved edits is parked, never discarded) and `assign_net_class` changes the project's net class as the headless run does. Closing is refused with a reason when the document is your active tab or is shown in a window of its own, so an agent never moves your tab. Nothing changes while "Allow agent connections" is off. See `docs/AGENT_SOCKET.md`.
