- **More files in Fabrication Outputs (#2489)** — the dialog has a tick box for each of IPC-2581, ODB++ (with a second box to write the job as a folder instead of one archive), the assembly drawing as a PDF (a page for each side), the assembly drawings as SVG (a file for each side) and the board's STEP model, beside Gerber, drill, pick and place and the test netlist. Generate makes every chosen file first and writes them together, so a drawing or a model that cannot be made writes nothing and says why. What the STEP model leaves out (holes, part models that could not be read) shows under the result and in Messages. The ticks are saved in the project when you save it, and an untouched project's file does not change; changing a tick can be undone like any other project setting.
