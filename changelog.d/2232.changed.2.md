- **New Project's folder checkbox names the folder (#2232)** — under Location, `Create "<name>" folder` is on by default and its label follows the name as you type it; with an empty name it reads "Create a folder named after the project". On, the project goes in `<Location>/<name>/<name>.snxprj`; off, straight into Location. Create stays off, with the reason shown, when the `.snxprj` already exists or the named folder is not empty, so nothing is overwritten.
