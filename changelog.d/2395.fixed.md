- **Side docks keep the width you gave them (#2395)** — the left and right docks remember the width they were dragged to. A smaller window still narrows them so the canvas keeps its room, but minimise and restore, maximise and restore, or a window resized down and back now return both docks to that width instead of leaving them narrowed. The saved dock layout stores these widths; a layout saved by an older build loads with the default widths.
