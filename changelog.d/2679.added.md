- **Annotations panel (#2679)** — View ▸ Annotations lists the notes, calculations, measurements, issues and decisions written as `#annotation(kind: …)[…]` blocks in the project's Design Notebook files (`notebook/*.snxnbk`), grouped by file and newest first, with kind chips, Part, Status and Date filters and a search field. A part chip opens the part's sheet with the part selected, a net chip highlights the net, and a reference to a part the design no longer has shows in amber. Blocks the panel cannot read are listed in Messages with their file and line.
