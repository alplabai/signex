- **Opening from the project tree and History restore no longer freeze the window (#859)** — double-clicking a schematic, PCB, symbol or footprint in the project tree, and Restore in the History panel, now read and parse the file on a background thread. A result that arrives after you closed the tab, all documents or the project is dropped instead of reopening it, and a second click on the same file while it loads opens one tab. While a restore runs, saving that document is refused with a Messages line (also after its tab was closed, until the restore's worker reports; a restore cancelled that way still lands in a clean tab reopened meanwhile, and a tab with unsaved edits keeps them with a Messages line saying a save would overwrite the restore), Save All reports it as that file's failure, and edits made meanwhile are kept instead of being replaced, a save of unchanged content does not count as an edit, and a finished restore never switches tabs or touches the tab you are working in. Failures still reach the Messages panel with the same text.
