- **Create Sheet says what reusing a file does (#1276)** — when the typed file already exists, the dialog shows the error in a box and offers **Use existing file** (formerly **Open it**) beside a disabled **Create**; Enter in the field no longer picks the existing file, so choosing another name is the default. If the project already has that file as a page, or another open sheet places it, a warning says that using it makes the sheet symbol a copy of that sheet. The **File** label carries the folder the path is relative to, a note says the symbol's File field is set to the path, and a footer hint explains **Later**.
