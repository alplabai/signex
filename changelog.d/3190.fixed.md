- **Restoring an imported library keeps its files byte for byte (#3190)** — With git set to convert line endings (`core.autocrlf = true`, common on Windows), a failed library update put the library's files back with CRLF line endings. Import repositories now turn that conversion off in their own git settings and mark every file `-text` in `.gitattributes`, and a restore turns it off in libraries imported by an earlier build too.
