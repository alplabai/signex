- **Links in the schematic PDF (#1298)** — a port jumps to the sheet entry it connects to and back, a sheet symbol and its entries open the child sheet's page, a global label jumps to the next page with the same label, a part whose datasheet is a web address opens it, and a `[label](address)` link in a note opens its address. Only web and mail addresses become links. The command-line tool writes a schematic PDF with `export_schematic_pdf`, watermark included; `links=false` leaves the links out.
