- **Deleting an in-use library symbol says what happens and offers Re-bind (#2572)** — The Delete Symbol? dialog counts the component rows that will show a broken symbol binding and lists the rows and sheets that use the symbol as key / value rows (the first six rows, then Show all). Re-bind all to… binds one picked symbol to every listed row, and each row has its own Re-bind…; the dialog then comes back with the new count, and once nothing uses the symbol it deletes it with a plain Delete.
