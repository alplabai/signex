- **For headless callers: `place_component`, `place_sheet_symbol`, `place_sheet_entry` and `sync_sheet_pins` now run (#2199)** — they were refused headless as window-only commands; now they take operands, a headless call without them is refused with the operand it needs, and `sync_sheet_pins` is an undoable document edit. In a window, without operands, nothing changes: Place Part opens the picker, the sheet tools arm and Sync Sheet Pins acts on the selection.
- **Edits that read the disk run when the reads land (#2199)** — an agent's or a headless edit whose checks need the project's closed sheets, a library row or a child file no longer reads them on the app's UI thread: they are read in the background and the edit runs, and is answered, once they land; a running Signex answers such an agent request then, not at once. If the sheet changed in between, the edit is refused with "the document changed while its project and files were read; retry" and nothing is applied. The wire, bus, label, power port and junction checks follow the same path.
