The footprint is read in the background and cached until its library changes. The free-text footprint field under the footprint drop-down is now labelled "Footprint override", since a name typed there is held over the picked footprint. On Graphite the header reads "Component" with the part's description, "Library: out of date" is a warn pill with a ghost Update button, the Library ID is mono with an ellipsis and a tooltip, and the label column is a fixed 92 px, so labels such as "Designator" are no longer clipped in a narrow dock.
