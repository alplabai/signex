- **New board and numbering from the command line (#2470)** — `new_pcb_document` takes the project (`document`) and the board's file (`name`) and answers with the new board's id and path, without the `save` capability. `annotate_schematic_quietly` and `force_annotate_all_schematics` take the sheet to number (`document`), and `reannotate_board` and `back_annotate_schematics` run from `document` (and `dry_run`) without their dialogs; each answers with every designator or value it changed, in one undo step.
