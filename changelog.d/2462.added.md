- **Compare Board with Schematic (#2462)** — Project ▸ Compare Board with Schematic… (also Compare with Schematic on the board's right-click menu and in the palette) lists every difference between the schematic and the board, grouped as missing on board, extra on board, net differences, footprint mismatches and value changes. Each row picks Update PCB, Update schematic or Skip; extra parts and footprint mismatches start skipped. Apply asks before it removes anything from the board, then makes one undo step on the board and one on the schematic. Jump links show the object in either editor, and Export report… saves the report as text.
