- **Live pattern mirrors, patterns of patterns and per-pad overrides in the footprint sketch (#2518)** — with a pattern selected, Mirror adds a mirror of it that follows the pattern on every bake, and Linear, Rectangular or Circular Pattern repeats every instance of it; a link that would make a pattern repeat itself is refused. Editing an attribute of a patterned pad asks This pad / All pads each time: This pad keeps the change on that pad alone, All pads changes the pattern's source.
