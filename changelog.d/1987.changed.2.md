- **One Parameters list for a sheet (#1080, #1987)** — the Title Block and Sheet Variables sections left Document Options ▸ General; their fields are now rows of the **Parameters** tab, edited the same way (Enter applies, one undo step). Every row shows its real value instead of `*`. New title-block fields **Author**, **Engineer**, **Organization** and **Address 1** to **Address 4** are saved with the sheet. Current Time, Current Date, Time, Modified Date, Document Full Path, Document Name, Sheet Name, Sheet Number, Sheet Count and Project Name are read-only rows. An empty **Date** now shows today's date, on the sheet and in the PDF, without saving it; a typed date is kept. Every row name works as a special string in any text, such as `${CompanyName}`, `${Author}`, `${CurrentDate}` or `${ModifiedDate}`. A long name no longer runs into its value.
