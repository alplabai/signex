- **One expression engine for parameters and fields (#1984)** — footprint sketch parameters now evaluate through the shared `signex-expr` crate. Expressions accept electrical units with SI prefixes (`100nF`, `4.7kΩ`, `10mV`), RKM values (`4k7`), unit algebra (`3.3V / 10mA` is `330Ω`, `2mm * 3mm / 1mm` is `6mm`), the functions `min`, `max`, `abs`, `sqrt`, `round`, `floor`, `ceil` and the constant `pi`. A sketch value must still be a length, an angle or a count, so a final area such as `2mm * 3mm` is refused as before. A bare `10m` is metres in a pad dimension. A sketch parameter refuses a literal whose suffix is only an SI prefix (`10m`, `1u`, `2n`) or an RKM value (`4k7`) with a parse error, so a typo never bakes as wrong copper, and refuses a parameter named `pi`, which every expression reads as the constant. A long chain of parameters that refer to each other is refused with an error instead of crashing Signex. `.snxfpt` files do not change.
