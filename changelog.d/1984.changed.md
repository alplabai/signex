- **One expression engine for parameters and fields (#1984)** — footprint sketch parameters now evaluate through the shared `signex-expr` crate. Expressions accept electrical units with SI prefixes (`100nF`, `4.7kΩ`, `10mV`), RKM values (`4k7`), unit algebra (`3.3V / 10mA` is `330Ω`, `2mm * 3mm / 1mm` is `6mm`), the functions `min`, `max`, `abs`, `sqrt`, `round`, `floor`, `ceil` and the constant `pi`. A sketch value must still be a length, an angle or a count, so a final area such as `2mm * 3mm` is refused as before. A bare `10m` is milli in a parameter and metres in a pad dimension. `.snxfpt` files do not change.
