- **Fast grid shortcuts (#1672)** — Fast grid 1 and Fast grid 2 (Alt+1 / Alt+2 in the Classic profile) snap the grid to 1.27 mm (50 mil) and 2.54 mm (100 mil), and Cycle fast grid (Alt+4) steps between the two; the visible grid follows unless it was set apart. They also run from the command palette. Before, these keys only said the command was not available yet.
