- **Fast grid shortcuts (#1672)** — Fast grid 1 and Fast grid 2 (Alt+1 / Alt+2 in the Classic profile) snap the grid to the two fast grids, and Cycle fast grid (Alt+4) steps between the two; the visible grid follows unless it was set apart. They also run from the command palette. The two grids are set in Preferences ▸ Theme ▸ Schematic Editor (Fast grid 1 / Fast grid 2, in mm; defaults 1.27 mm (50 mil) and 2.54 mm (100 mil)); a value that is not a number above zero, or is finer than 1 nm, stops the Save: the dialog stays open with the typed value, the reason shows under the fields and in Messages, and nothing is saved until it is fixed. Before, these keys only said the command was not available yet.
