- **Selecting and dragging many items no longer rescans the whole sheet per item or per frame (#1334, #1335)** — the selection overlay builds the item bounds once per draw instead of once per selected wire, label or drawing. A move-drag now draws the items it leaves alone once, in a retained layer, and each frame draws only the moving items (and, with "keep wires", the wires it stretches) on top, so a frame costs the size of the selection rather than the size of the sheet; the layer is drawn again only on a zoom, a pan, a theme change or an edit. **Intended change:** while dragging, a moved item always draws above every unmoved one, even where it normally sits under an overlapping item; it returns to its place when dropped.
