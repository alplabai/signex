- **Design checklist (#1291)** — Project ▸ Design Checklist opens the project's review checklist as a document tab: start from the Release review, Prototype build or Blank template, track each item as Open, Done or Waived with a reason, owner and notes, see progress per stage, and link an item to the ERC or DRC run, the title block, a project requirement or a design object. Run checks shows each linked check's result, and a passing check offers Mark done. The checklist is stored in the project file and written by Save; the `project_checklist` and `project_*_checklist*` commands read and edit it from the CLI or an agent.
