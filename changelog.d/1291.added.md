- **Design checklist (#1291)** — Project ▸ Design Checklist, or the project's row in the Projects panel, opens the project's review checklist as a document tab: start from the Release review, Prototype build or Blank template, one of your own saved templates, or another project's checklist; track each item as Open, Done or Waived with a reason, owner, notes and a history of who changed what; see progress per stage and filter by state or to your own items with counted chips; and link an item to the ERC or DRC run, the title block, a project requirement or a design object, picked from a list. Run checks shows each linked check's result, a passing check offers Mark done, and a design-object link opens its sheet with the object selected. More offers Save as template, Export CSV and Reset from template. The checklist is stored in the project file and written by Save; the `project_checklist` and `project_*_checklist*` commands read and edit it from the CLI or an agent.
