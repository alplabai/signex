- **Change Component follows a pin mapping (#2954, #2851)** — the dialog's Kept line names the net each pin keeps, and a swap can follow a pin mapping given by hand in one undo step, moving the wire on a remapped pin with it. `change_component id=.. library=.. part=.. [pins=old:new,..] [dry_run=true]` swaps a part from the CLI and answers with the pin table (old pin, new pin, net).
