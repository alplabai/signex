- **Detached modals no longer float above other applications (#622)** — detached dialogs (Preferences, Print/BOM Preview, Parameter Manager, ...) use a normal window level instead of always-on-top, so they stay out of the way of other apps and no longer cover the in-window shortcut sheet, tour and confirm dialogs; iced 0.14 has no owner-window option, so a dialog can still be covered by the main window and is recovered from the OS window switcher.
