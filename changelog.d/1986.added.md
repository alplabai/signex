- **Expressions in part fields (#1986)** — a part's value or field that starts with `=` is calculated: `= Rbase * 2` reads the part's own field, `= R1.Value / 2` reads another part's, and sheet and project variables work too. The sheet, PDF, SVG and print preview show the result with its unit (`20kΩ`), the Properties panel shows the expression with the result under it, and the file keeps the expression. When R1 is renumbered by annotation, `R1.Value` follows it. An expression that cannot be calculated (an unknown designator, mismatched units, two parts that refer to each other) shows as typed and is listed in the Messages panel when the sheet is saved.
