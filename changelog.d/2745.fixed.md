- **A union moves as one, however it was selected (#2745)** — a box, a lasso, Ctrl+click, Shift+click, Select Connected or a Move pick on one member now selects the whole union, so a drag or nudge no longer leaves the other members behind. The Unions panel's name field keeps a trailing space while you type, so a name like "Input filter" can be typed, and clearing the field no longer snaps the old name back.
