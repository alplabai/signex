- **Net Parameters directive (#1489)** — Place ▸ Directives ▸ Net Parameters (the old Parameter Set row) puts a flag on a wire that gives its net a net class, a diff-pair class and routing rules: width, clearance, via diameter and hole, and current as information. The flag can list the values, so the intent reads on the sheet. Its Properties show the flag as a drawing linked to the rule rows. From scripts and agents, `place_parameter_set at=.. [class=..] [diff_pair_class=..] [width=..] [clearance=..] [via_diameter=..] [via_hole=..] [current=..]`; a point off a wire is refused.
- **Net Blanket (#1281)** — the Blanket is now called Net Blanket. It gains a track width, a "Pour on nets" choice (Normal / Keep short, stored for the board) and "Include nets that only cross the edge" (off by default). Power nets such as GND are never caught. Its Properties show the outline over the circuit, the nets it catches (hover a row to light the net on the sheet) and the outline as X / Y and Width / Height; the ERC exclusions are as before.
- **Classes reach the netlist (#1281, #1489)** — a net takes the class of a Net Parameters directive on it, else of the Net Blanket that catches it, else of the project's class patterns, in the project netlist too.
- **Differential pair classes (#1282)** — Design ▸ Differential Pair Classes… sets each class's impedance, width and gap and whether pairs are matched by suffix; OK is one undo step of the project. A Differential Pair directive can name its class, and a pair's partner is now also found by `DP`/`DN` and `+`/`-` suffixes.
- **Rules from the schematic (#1489)** — Update PCB lists the width, clearance and via rules the Net Parameters directives ask for and writes them into the project's design rules on Execute; the Rules tab shows them as "from schematic".
