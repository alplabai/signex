- **Project previews on the Start screen (#2262)** — each project row shows a small drawing of the project: its board when it has one, else its root sheet, with a PCB or SCH badge. The preview is made when you save and kept in a cache in the settings folder, so the Start screen never opens project files to draw it. A project not saved since previews were added shows "No preview yet"; a project missing on disk shows an empty dashed tile. See `docs/PROJECT_THUMBNAILS.md`.
