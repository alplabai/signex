- **Library server no longer silently overwrites primitives (#1445)** — `POST /symbols`, `/footprints` and `/sims` are create-only (409 on an existing uuid), and replacing goes through `PUT` with an `If-Match` revision like component rows; a stale or missing revision is refused (409 / 428). The library client keeps the revision with each copy it reads, so a later read of the same primitive cannot rebase an older open copy, and it refuses to work with a server too old to send primitive revisions. Existing primitives start at revision 1. An older client that used `POST` to update a primitive now gets a 409.
