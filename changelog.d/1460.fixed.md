- **Library server no longer silently overwrites primitives (#1445)** — `POST /symbols`, `/footprints` and `/sims` are create-only (409 on an existing uuid), and replacing goes through `PUT` with an `If-Match` revision like component rows; a stale or missing revision is refused (409 / 428), and the library client tracks revisions for you. Existing primitives start at revision 1.
