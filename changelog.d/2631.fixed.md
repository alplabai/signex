- **Components panel follow-ups (#2631)** — Recently placed counts only parts that were placed: Place with no sheet open or with the library closed adds nothing. Row thumbnails are read again when their library is re-read after a save or an external edit, and the old drawing stays up until the new one arrives. A thumbnail is no longer drawn again on every frame; it is redrawn only when its symbol, the theme or the scale changes. The row menu's Place shows the key the active profile binds to accepting a placement, and only that key places from the menu: Enter in the default profile, none in Classic, the new key after a rebind.
