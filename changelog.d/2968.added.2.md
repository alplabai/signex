- **Re-sync from sheets: review the changes (#2968)** — the block diagram tab's Re-sync applies added blocks and renamed or moved sheets at once, as one undo step, and opens a review side sheet when a block would become unlinked: each such block is a checked row, previewed on the diagram, and Apply selected unlinks the checked ones as one undo step. A block still named after its old sheet file takes the new name; a name you typed is kept. From the command line, `regenerate_block_diagram unlink=skip` leaves those blocks and lists them under `skipped`.
