- **Rule drawings in the Rules tab (#2530)** — the selected rule, class pair or object pair is drawn on the board ground with its values on the drawing: clearance, track width, via, holes, board edge, silkscreen, solder mask, paste and courtyard. Click a value to type it (Enter commits, Tab moves to the next value) or drag its ● handle; the grid cell follows. The preview is full width and has an Expand button.
