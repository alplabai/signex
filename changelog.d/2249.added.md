- **Tile documents in the main window (#2249)** — Window ▸ Tile Horizontally stacks the open documents in panes, one above the other, and Tile Vertically puts them side by side; each pane is a working editor (sheet, board, symbol, footprint, library). The pane with the accent ring is the active document; press another pane to make it active. Window ▸ Untile, or closing down to one document, shows one document again. Undocked document windows are still arranged on the screen as before. The new `untile_documents` command is in the command palette; the built-in keys are `W H`, `W V` and `W U` (default profile) and `Shift+Alt+H`, `Shift+Alt+V` and `Shift+Alt+U` (classic profile).
