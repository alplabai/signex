- **Block diagram tab (#2796)** — File ▸ New ▸ Block Diagram and opening a `.snxblk` show the diagram in its own tab: add blocks and ports, connect them with the Connect tool, label each connection with its interface, group blocks, edit everything in Properties, move blocks on the canvas, undo, redo and save. Every edit is also a command with a JSON answer (`block_add`, `block_set`, `block_link`, `block_group`, `query_block_diagram` and the rest), for `signex-cli run` and agents.
