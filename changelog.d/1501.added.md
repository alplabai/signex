- **ERC rule profiles (#1085)** — save a project's ERC rules as a reusable `.snxrules` profile, update a project from its profile after reviewing a diff, and get a note when the local profile has drifted. ERC reports now name the profile and rule-set hash. Existing prefs-based rules become a `User Default` profile on first run. The ERC CSV export now starts with a `# Rule set,<name>,<sha>` row before the header, so a parser that expects the header on the first line must skip it.
