- **Unknown `.snxlib` keys are kept on save (#1435)** — a library holding keys this build does not model (at the root, in `[library]`, `[users]`, `[[classes]]`, `[tables.<name>]` or a cached price record) is saved as the text it was read from with only the edited content changed: unknown keys, key order, comments and untouched rows stay byte-for-byte. A key goes only with the thing it belonged to — a removed class, user or price record takes its unknown keys with it, and a renamed class keeps them.
