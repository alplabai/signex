- **Unknown `.snxlib` keys are kept on save (#1435)** — a library holding keys this build does not model (at the root, in `[library]`, `[users]`, `[[classes]]` or inline `classes`, `[tables.<name>]` or a cached price record) is saved as the text it was read from with only the edited content changed: unknown keys, key order, comments and untouched tables stay byte-for-byte. An edited table's TSV block is still written canonically (rows sorted by `row_id`, blank lines dropped), and a file with CRLF line endings is written with LF as before. A key goes only with the thing it belonged to — a removed class, user or price record takes its unknown keys with it, a re-fetched price record drops the old fetch's, and a renamed class or table keeps them. A save that would lose any other unknown key is refused.
