- **Unknown `.snxlib` keys are kept on save (#1435)** — root, `[library]`, `[[classes]]` (matched by class key, so removing or reordering classes never moves a key) and `[tables.<name>]` keys this build does not know are written back instead of dropped on the next edit. The first save re-sorts and reformats a file's keys; later saves are byte-stable. Unknown keys inside `pricing` records and `column_types` entries are still dropped (pricing is a re-fetchable cache).
