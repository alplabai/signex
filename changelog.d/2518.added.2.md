- **Sketch values on the drawing (#187)** — dimensions show `name · value` on the drawing instead of a letter; click one to edit it in place, Enter applies and re-solves, Esc cancels.
- **One constraint menu (#188)** — a right-click of a constraint glyph or value offers Edit value, Make parameter, Convert to reference and Suppress (greyed, with the reason), Select constrained entities, Show conflicts, Delete.
- **Pattern glyphs (#187, #191)** — patterns draw a glyph (`L×4`, `G×3×4`, `P×8`) that selects the pattern and opens its menu; count and spacing edit on the drawing, and a click on an instance of a selected rectangular or circular pattern suppresses it.
- **Conflict badges (#187)** — conflicts show as a small red badge by the conflicting dimension; each Properties conflict row has a Remove button.
