- **Board reports (#2404)** — The Reports menu, the Board panel's Reports button and the command palette open Board Reports on the board in view: its bill of materials (part types kept out of the BOM are left out), its netlist, each net's routed length with its track and via counts, and a component report with each part's designator, footprint, position, rotation and side. Each table exports as CSV, and an agent can read each one as structured data.
