- **Board reports and the board PDF no longer replace a file without asking (#2470)** — `export_board_report` and `export_board_pdf` run from `signex-cli` (headless or attached) refuse a `path` where a file already is unless `overwrite=true` is given, and never write over a Signex document or into a `.git` folder. The notebook exports, including the Export PDF dialog and the measurement lane's CSV export, refuse a `.git` folder too, and on Windows a name ending in a dot or a space or holding `:`. Both board commands now answer once the file is written.
