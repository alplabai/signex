- **More of Signex for agents in a running window (#2470)** — an agent connected to a running Signex can now number a project's sheets (`annotate_schematic_quietly` with the sheet named), write a board's fabrication files, its PDF and its report CSV into the project folder (`fabrication_outputs`, `export_board_pdf`, `export_board_report`; a path outside the project is refused), fit the view (`zoom_to_fit`) and open, close, collapse or expand a dock panel with the new `set_dock_panel panel=<key> state=<open|close|collapse|expand>` command. `signex-cli run --attach` sends these, and the tiling commands, instead of refusing them.
