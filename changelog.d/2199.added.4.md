- **Parts and hierarchy from the command line (#2199)** — `place_component library=<id or path> part=<row id or part number> at=x,y` places a row of an open library (a project's libraries open with the project; the stock library is always open) through the same commit as a pick and click, with optional `unit`, `designator`, `value`, `rotation`, `mirror=x|y` and `document`, and answers with the designator, unit and every pin's tip, so the next edit can wire it: `signex-cli run demo.snxprj place_component --arg library=<id> --arg part=STOCK-R --arg at=63.5,63.5 --save`. Another unit of a placed part shares its designator (`unit=2 designator=U1`). `place_sheet_symbol` (two corners, a name and the child file it refers to, never written), `place_sheet_entry` (a sheet symbol by name and a point on its border) and `sync_sheet_pins` (a sheet symbol by name; answers with the entries added, removed and kept) run from operands too, and all four can be edits of `apply_edits`. A part, sheet symbol or entry whose pin tip or entry lands on a wire, junction, label, entry or another pin is refused: an edit from operands connects nothing it does not name. A bus-named entry on a bus, and a pin tip or entry on a no-connect marker, are refused too, and so is a sheet symbol whose file is its own sheet, one above it, or one that places it below. A sheet symbol whose file's labels would short or rename project nets is refused unless `allow_merge=true`. A unit already placed on any sheet of the project, closed ones included, is not placed again.
