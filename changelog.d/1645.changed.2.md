- **Standard shortcuts use ⌘ on macOS (#1645)** — in both built-in profiles Save, Undo, Copy, Find and the rest of the standard set now follow the platform key (⌘ on macOS, Ctrl on Windows and Linux, unchanged there). Chords the system owns (⌘Q, ⌘H, ⌘M) stay on Control, so Altium's Ctrl+W (Place Wire) stays on Control, while macOS adds ⌘W to close a document, ⌥⌘F for Replace and ⇧⌘Z for Redo. A custom profile that still binds the standard set to Control is offered a one-time "Use ⌘ / Keep Control" choice on macOS; "Use ⌘" keeps a backup of your shortcuts file first.
