- **Standard shortcuts use ⌘ on macOS (#1645)** — in both built-in profiles Save, Undo, Copy, Find and the rest of the standard set now follow the platform key (⌘ on macOS, Ctrl on Windows and Linux, unchanged there). Shortcuts whose ⌘ form macOS reserves (⌘Q, ⌘H, ⌘M) stay on Control, as does Altium's Ctrl+W (Place Wire); on macOS, ⌘W closes a document, ⌥⌘F opens Replace and ⇧⌘Z redoes. A custom profile that still binds the standard set to Control is offered a one-time "Use ⌘ / Keep Control" choice on macOS; "Use ⌘" keeps a backup of your shortcuts file first.
