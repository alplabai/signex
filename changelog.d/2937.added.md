- **Footprint assignment from the command line (#2937)** — `assign_footprint` sets a placed part's footprint as Tools ▸ Assign Footprints does, `change_footprint` with operands swaps a board footprint as the footprint picker does, and `query_footprint_assignments` lists each part's footprint and whether an open library has it. A footprint that is not found, or lacks a pad for a pin, is refused with the pins.
