- **Assembly drawings as PDF pages and SVG (#2486)** — Board Print / PDF has two more page sets, Assembly Drawing, Top and Assembly Drawing, Bottom: each draws that side's fab, assembly, designator and fiducial layers, every part's designator, the board outline and the dimensions on a page of its own, the bottom read from below when Mirror the Bottom Side is on. Export Assembly SVG in the same dialog, and Assembly Drawings as SVG in the Reports menu and the command palette, writes the same drawings as `<board>-assembly-top.svg` and `<board>-assembly-bottom.svg` in a folder you pick, at 1:1 in millimetres. The command-line tool writes them with `export_assembly_svg` and prints the pages with `export_board_pdf layers=assembly_top,assembly_bottom`; an agent reads one drawing as SVG text with `board_assembly_drawing`.
