- **Sheet Entry, Library Editor and Close All Documents menu rows work (#2247)** — Place ▸ Sheet Entry selects the Sheet Entry tool, Tools ▸ Library Editor opens or focuses a Library Browser tab, and Window ▸ Close All Documents closes every tab (unsaved documents are kept as drafts, as from the tab menu). The new `open_library_browser` and `close_all_documents` commands are also in the command palette and can be given a key.
