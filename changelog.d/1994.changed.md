- **The first-run tour card is shown once, and only a deliberate gesture closes it (#1994)** — the card now saves that it was shown the moment it opens, so a later launch never shows it again even if it was never closed. In that first session it closes on ✕, Esc, or a pointer gesture on a canvas (click, right-click, double-click, box select, drag-move, wheel zoom, pan); a mere hover and the fit and zoom commands from the Home key or the menu no longer close it.
