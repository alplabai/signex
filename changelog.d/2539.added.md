- **Gerber and drill reader (#2539)** — a new `signex-gerber` crate reads Gerber X2 and RS-274X images, Excellon drill files and the Gerber job file back into exact nanometre shapes with their X2 nets, pins and aperture functions. It reads every file Signex's own fabrication outputs write with no problem. A file it cannot read in full is still drawn: each command it does not understand, each undefined aperture or macro, and each drill tool without a size becomes a message with its file and line, and the objects it could not build are kept so the viewer can mark them. Other files in a package are listed as not read. It is the base of the Gerber viewer, whose tab comes with the shared document tab shell.
