- **A deliberate per-part override of footprint, Manufacturer or MPN now survives the library row's next version (#2004)** — a placed part remembers the row values it last agreed with, in a new `library_stamp` table of its entry in the schematic file (the format token is unchanged; older builds keep the table). A field you did not touch follows the row as before; one you changed stays as you set it, and "Update from library" no longer overwrites it. When both the part and the row changed a field, the Library Updates window shows a "Keep mine" / "Use library value" choice per part and field (default: keep mine) and applies the answers in one undo step; "Update from library" itself keeps your value and says so in Messages and leaves the part to be offered in the window again. A part from an older file whose row moved and whose value differs gets that choice, instead of being overwritten. The window asks again each time it opens until the choice is answered; Skip all and Cancel do not count as answering.
