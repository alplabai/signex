- **ERC on demand for agents and the command line (#2199)** — `check_erc document=<sheet>` checks the project of the named sheet as Run ERC does (closed sheets read off the UI thread) and answers with a report: each finding's rule, severity, message, evidence, objects, sheet and a key that names the same finding in every run, the findings a waiver hides with that waiver, and the waivers that lapsed. `signex-cli run demo.snxprj check_erc --arg document=main.snxsch`. Each answer carries a `run` number; `baseline=<run>` adds the keys that are new and gone since that run, so an agent can tell what its own edits introduced. It writes nothing to the ERC panel or Messages; Run ERC is unchanged.
