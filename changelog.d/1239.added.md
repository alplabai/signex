- **Several documents per library component (#1231)**: a component row can carry more than one document (a datasheet per manufacturer, an errata, an application note), each with an optional label and the first one as the primary. The Datasheet tab adds, removes, relabels and reorders them, and the Properties panel lists a placed part's documents. Rows with one unlabelled datasheet are stored byte for byte as before and keep their content hash. **Mixed versions:** once a row has a label or a second document, an older Signex cannot mount that library, and an older library server drops the extra documents when the row is written. Upgrade every client and the library server together before using this.
