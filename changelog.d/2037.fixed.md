- **Find, the command palette, the Projects menu, the Components drag ghost and queued descents in an undocked window act on its sheet (#2037, #1966)** — Find opened from an undocked window now searches, selects and replaces in that window's sheet and appears only in that window; it closes with the window. A command picked from the palette that was opened in an undocked window runs on that window's sheet, the palette lists only the commands that window's selection enables, and its symbol rows focus symbols of that sheet. The Projects menu right-clicked in an undocked window appears only there and acts on that window's tree (expand, collapse, refresh); picks that open a tab, a dialog or a file run on the main window. The document-tab menu now appears only in the main window instead of in every window. A Components row dragged inside an undocked window shows its ghost on that window's canvas, as in the main window, and no longer follows a pointer that moved into another window. A descent through a sheet symbol queued from an undocked window is checked when it lands on the main window: if the window closed, shows another sheet, or the sheet symbol was deleted, re-pointed or entered through another placement, nothing is opened and the Messages panel says why. Still open: the History panel in an undocked window shows the main window's file history.
