- **DRC panel before and after a run (#2449)** — before the first run the panel lists the 15 base rules with their rule text, how to write each and whether this board writes it, uses the default or always checks it, with "Write it" and "Set it in Rules" links that open the Rules tab. After a run, clearance, short, unconnected and keepout tiles list one category, notices stack above the rule, layer and severity filters, groups have a Rule link that opens the rule, and rows show the layer, position and object count. Waive opens the same form as ERC: a multi-line reason and an author, both required. A DRC waiver now keeps its author in the board file (`author` in `[[board_options.drc_waivers]]`, written only when set; older boards load unchanged), and `waive_drc_violation` takes `author=`.
