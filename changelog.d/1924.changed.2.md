- **Signex lists its open projects even with agent connections off (#1924)** — every open project gets a small entry and a lock file in your per-user runtime folder (no socket, no token, nothing listens; the "Allow agent connections" setting still decides that). `signex-cli` uses it to refuse to run headless on a project that is open in Signex, telling you to turn the setting on so the agent can work through your open window instead of beside it. The entries go when the project closes or Signex quits.
