- **Requirements editor in the Project tab (#2339)** — a Requirements section lists the project's requirements with their kind, fields and an Enabled switch; add one by kind, edit its fields in place (a value that is not valid is refused with the reason), turn it off or remove it, and Run checks to see each requirement pass or fail with its evidence and when the checks last ran. Every edit is one undo step and is written when the project is saved; the same actions are catalog commands (`project_add_requirement`, `project_set_requirement`, `project_remove_requirement`, `project_enable_requirement`, `project_run_requirements`).
