- **Parameter Manager CSV export and import (#1295)** — Export… and Import… in the Parameter Manager footer, and the `export_parameters` and `import_parameters` commands in the palette, write the active sheet's part parameters to a CSV file and read an edited file back. Import opens a preview of the changes; nothing changes until Apply, and Apply is one undo step. Value and Footprint columns are never imported, and an import never removes a parameter.
