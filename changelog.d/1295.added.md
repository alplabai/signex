- **Parameter Manager CSV export and import (#1295)** — Export… and Import… in the Parameter Manager footer, and the `export_parameters` and `import_parameters` commands in the palette, write the active sheet's part parameters to a CSV file, one line per part keyed by its unique id, and read an edited file back. Import opens a preview of the added and changed parameters and the lines that match no part; nothing changes until Apply, and Apply is one undo step. Value and Footprint columns are never imported, and an import never removes a parameter.
