- **Parameter Manager CSV export and import (#1295)** — Export… and Import… in the Parameter Manager footer, and the `export_parameters` and `import_parameters` commands in the palette, write the part parameters of the sheets the Parameter Manager lists (the active sheet, or every listed sheet with All sheets, then with a Sheet column) to a CSV file, one line per part keyed by its unique id, and read an edited file back into those sheets. Import opens a preview of the added and changed parameters and the lines that match no part; nothing changes until Apply, and Apply is one undo step, across every sheet it changes. Value and Footprint columns are never imported, and an import never removes a parameter.
