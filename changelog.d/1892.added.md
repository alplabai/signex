- **Edit the bundled stock library in Signex (#1892)** — with `SIGNEX_EDIT_STOCK=1`, a build run from a source checkout mounts `assets/stock-library/Stock.snxlib` writable, so maintainers edit the stock symbols, footprints and rows in the normal editors and ship the saved files by PR. An installed copy stays read-only. The committed files are now the source of truth: the stock tests check that every shipped id survives instead of matching the seed generator, which needs `--force` to overwrite edits.
