- **Pin table tab (#2817)** — Edit pins in table… on the symbol editor's Pins tab opens the symbol's pins as a document tab next to the symbol: all seven columns typed in place, a Check column for duplicate numbers and missing names, tick rows to set their type, part, length, orientation or hidden state together, and Paste rows to read a datasheet pin table (update by number, append or replace all). Every edit is one undo step on the symbol and saves with it.
