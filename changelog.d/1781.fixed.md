- **Re-init picks the right branch in three more cases (#1780)** — when it has to re-create a deleted `.git/HEAD`, the usual order (`main`, `master`, the last checked-out branch, the newest) now applies even if the new HEAD lands on an existing branch, and a branch that tracks the library is used instead of refusing; a HEAD that was never deleted, such as a deliberate orphan branch, is left where it is; and where symbolic links are not supported (`core.symlinks=false`) a linked file is indexed as a link, so nothing is left staged.
