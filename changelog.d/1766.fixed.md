- **Export, New Project and Save As panels start in the right folder (#1766)** — File > Export > PDF, Netlist, Bill of Materials and ERC Report open in the active project's folder, New Project beside it, and Save As in the document's own folder, instead of the OS's last-used one (the bundled Sample Project leaves the folder to the OS); the suggested file name is the project or document name, a finished PDF export names the written path in the Export window's footer until the settings change, and every export failure is a Messages-panel line as well as a notice.
