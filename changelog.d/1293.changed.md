- **The Project tab's Variants section is a Variant Manager (#1293)** — pick the active variant in the top bar, filter the parts and show only the rows that differ; the list shows what each variant fits against Base, `+` adds "Variant N" and opens its name, and a card per variant sits over a parts by variants matrix of Fitted / Not fitted, read from every sheet of the project with the BOM's own fit rule. A part's value is the one the BOM lists: a value written as an `=` expression shows evaluated (`20kΩ`), not its source text, and the filter finds a part by its designator or by its value as written or as shown (`Rbase`, `=` and `20k` all find `= Rbase * 2`). The typed name box and its Add button are gone. Cells are read-only for now.
