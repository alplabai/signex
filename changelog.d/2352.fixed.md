- **The PCB Active Bar has the full tool layout (#2352)** — a board tab's Active Bar now has the footprint editor's layout in the usual PCB tool order: selection filter, Move, Align, the place tools (component, pad, via, track, arc, fill, solid region, polygon pour, string, dimension, keepout), interactive routing, Board Sketch and Rotate View. Move and Rotate View run their commands on a click and open a dropdown on a right-click (Move, Move Selection, Rotate, Rotate Clockwise, Flip Selection; the four view turns), greyed by the same rules as their menu rows. Tools the board editor cannot run yet are greyed, with a tooltip that says so.
