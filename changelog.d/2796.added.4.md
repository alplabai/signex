- **Block diagram tab: Power tree, Re-sync and export (#2796, #1313)** — the tab's view switch shows the project's power tree read from the schematic: each rail with its source or converter, its voltage and total draw, and its loads, with budget bars and a Rails list. Re-sync rebuilds the open diagram from the sheet hierarchy as one undo step, keeping the layout. SVG and PDF… open an export popover (format, colours, title block, file). The Projects tree shows an open diagram with its own icon. A command line run can edit, query or export a diagram by path without opening it first, and a diagram save is no longer written over a file another program changed.
