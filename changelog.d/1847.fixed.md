- **Remove on a library unmounts it and deletes only its own files (#1847)** — Excluding or deleting a library from the project tree now closes it, so its parts stop being served. Delete removes the library file and its symbol, footprint, simulation and datasheet files, removes its own lock files, keeps the primitive folders when the manifest sits in the project folder or beside another library (listed in Messages), leaves any other file, and the dialog says how many placed parts on open sheets use the library.
