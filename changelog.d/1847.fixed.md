- **Remove on a library unmounts it and deletes only its own files (#1847)** — Excluding or deleting a library from the project tree now closes it, so its parts stop being served. Delete removes the library file and its symbol, footprint, simulation, class, 3D model and datasheet files, removes its own lock files, keeps the primitive folders when the manifest sits in the project folder, beside another library or beside a project or design file (listed in Messages), leaves any other file, and the dialog says how many placed parts on open sheets use the library. A delete waits for a running library write or mount, is refused while a primitive in the library's folders has unsaved changes, unmounts the library even when another open project lists it, and closes the tabs of the primitives it removed.
