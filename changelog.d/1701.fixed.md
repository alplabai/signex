- **Library range filters and search index follow the template slots (#1701)** — the library search index keys its number filters by the class-template slot names (`value`, `tolerance`, `voltage_max`, …) and records a version, so an index built before measurements were stored in base units is refused and rebuilt instead of mixing old and new values. In a Library Browser tab, clicking the table already on screen no longer clears its range filters, a range-filter keystroke no longer runs the full app refresh, and the Place Component picker names filter columns as the browser does.
