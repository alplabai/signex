- **Edit a placed object's position, rotation, size and parameters in Properties (#2418)** — a placed part's Position and Rotation, a sheet symbol's Position and Size, and a part's parameters are now edited in place: type a value and press Enter, or pick a rotation. Each edit is one undo step, lengths are read in the panel's unit and Y from the sheet's page origin. Wires, buses, bus entries, junctions, no-connects, No-ERC directives, sheet entries, labels, power ports and text notes get an editable Position the same way. A locked object shows its rows read-only with the lock's reason. The same edits run from the new `set_object_position`, `set_object_rotation`, `set_sheet_symbol_size` and `set_symbol_parameter` commands for the CLI and agents.
