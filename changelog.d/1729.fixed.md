- **Library commits skip OS clutter and survive an unreadable file (#1729)** — versioned libraries now carry the managed `.gitignore` block projects get (new libraries, Enable Version Control, and older libraries at their next commit), so `.DS_Store`, stranded `*.tmp` and write-lock files never reach a commit, and a pending file that cannot be read no longer stalls every later commit: the save's own change lands, the file stays pending and the Messages panel names it each time.
