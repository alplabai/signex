- **Rules manager (#2398)** — Design ▸ Rules opens the project's design rules as a document tab: Clearance and Routing sub-tabs, one row per rule with its scope, layer, objects, limits and severity edited in place, a text view of the same rules, search and filters. Each edit rewrites only that rule's text and is one undo step. Rows show the findings, worst value and margin of the last Run DRC (or why the cell is blank), flag shadowed, conflicting and class-lowering rules, and explain which rule governs a net and why. Agents and the CLI drive it with `rules_list`, `rules_get`, `rules_add`, `rules_set`, `rules_remove`, `rules_enable`, `rules_effective`, `rules_explain` and `rules_conflicts`. A rule can be turned off with `disabled rule ...` in the text.
