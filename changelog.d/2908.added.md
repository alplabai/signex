- **File ▸ Save Project As… (#2908)** — copies an open project into a new folder under a new name, in this version's format: the project file with its current settings, and every sheet, board and project library it lists. Documents with unsaved edits go into the copy with those edits, the others byte for byte; the open project and its files are not changed and its edits stay unsaved. The copy then opens beside the project. A folder that already holds files is refused. A project written by a newer Signex, which opens read-only, offers Save Project As… on its Save Failed card and in the Close Project and Exit prompts, so its unsaved settings can be kept in an editable copy.
