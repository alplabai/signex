- **Agents list, read and address documents by id (#2172)** — every document has a persistent id stored in its own file (a project gets a `document_id` key; sheets, boards and symbol or footprint files already carried one). `list_documents`, `document_info`, `resolve`, `find` and `read_document` answer with data, and `undo`, `redo`, `save_document`, `save_document_as`, `close_active_document`, `color_net` and `clear_all_net_colors` run by id or path on that document alone: a headless call must name it, and it never touches the active tab, focus, panels or selection. Save As gives the copy a new id, and a file copied outside Signex gets a new id with a Messages warning.
