- **Update an imported library (#3123)** — Importing into a folder that holds an imported library offers to update it from the source: one new commit that replaces only what the converter wrote, with a warning when the library has commits of its own and a clear reason when it cannot be updated (no history, uncommitted changes, unsaved work in Signex). The result card says where the library was mounted, which commit the import made and which libraries it requires.
