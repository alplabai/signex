- **Sheet-entry references as point operands (#2199)** — a point operand also takes `<sheet name>.<entry name>` (`Charger.SDA`), the connection point of that entry (sheet pin) of a sheet symbol on the target sheet, accepted off the grid like a part pin tip: `signex-cli run demo.snxprj place_wire --arg start=U1.3 --arg end=Charger.SDA --save`. The end names exactly that sheet pin; the answer's `ends` carries the reference as given. A sheet or entry that does not exist, two sheet symbols or two entries with one name, and a name that a part and a sheet both carry are refused with the reason. A bus takes none. A sheet name may contain a space (`Power Stage.SDA`); the value is split at the first `.`.
