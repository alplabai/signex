- **Fab tier profile cards (#2537)** — the setup cards of New Project, New PCB and the Project setup section are now the fab tiers **Standard**, **Advanced** and **HDI**, plus **Custom**, in a 2 x 2 grid; Hobby 2-layer is gone. The copper layer count is its own stepper on every card (2 to 32, in steps of 2) and no longer switches the profile to Custom. The cards and the tier's `fab_*` DRC rules read one tier table, so a new board's defaults pass its own fab rules: clearance / track / via / drill are Standard 0.15 / 0.2 / 0.5 / 0.25 mm, Advanced 0.1 / 0.125 / 0.4 / 0.2 mm and HDI 0.075 / 0.075 / 0.25 / 0.1 mm (the HDI `fab_via` floor moves from 0.3 / 0.15 mm to 0.25 / 0.1 mm). The Customize field "Manufacturer rule template" is now **Fab tier**, which mirrors the picked card.
- **Profile card hover (#2537)** — a hovered profile card now fills with the hover colour instead of drawing a hairline border.
