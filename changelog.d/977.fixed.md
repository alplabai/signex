- **PCB files no longer merge pads or lose layer types (#104)** — `.snxpcb` now keys each pad to its footprint by uuid, so footprints sharing a reference designator keep their own pads, and the stackup round-trips layer types; format is `snxpcb/1.1` and older files still open. `.snxsch`/`.snxpcb` accept any minor version of the current major (a newer file keeps its own version token on save) and a different major is refused naming both versions. A new library's first file is written atomically.
