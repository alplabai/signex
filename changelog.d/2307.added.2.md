- **DRC rule language (#2307)** — DRC rules can be written as text in a rule profile or the project: clearance scoped by net, net class, net pattern, layer or object pair, track width limits and via diameter and drill minimums, each with its own severity. The most specific rule wins, even when it is looser; boards without rule text check exactly as before. Rules that do not compile are named in Messages and skipped. See `docs/DRC_RULES.md`.
