- **DRC rule language (#2307)** — DRC rules can be written as text in a rule profile or the project: clearance scoped by net, net class, net pattern, layer or object pair, track width limits and via diameter and drill minimums, each with its own severity. The most specific rule wins, even when it is looser, and each net of a pair keeps its own rule; boards without rule text check exactly as before. A rule that does not compile is skipped, and a syntax error drops the whole rule text; both are named in Messages and flagged beside the DRC results. See `docs/DRC_RULES.md`.
