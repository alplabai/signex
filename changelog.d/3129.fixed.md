- **A pin name with a control character no longer loses the symbol file (#3129)** — a CR or another control character in a pin's number, name, description or function was saved into the `.snxsym` and the file then never opened again. The Symbol Editor now refuses such text where it is typed or pasted and a save refuses it, naming the symbol, the pin and the character (for example U+000D). A file already written this way opens with the characters removed, says in Messages what was removed, and stays read-only until you save it yourself: Save All, autosave, commands and agents leave the file as it is until then. A `.snxsim` model body refuses the same characters, tab and line breaks aside.
