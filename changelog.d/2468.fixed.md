- **Footprint editor draws the board colours (#2468, #2375)** — pads, silkscreen, assembly layers, the board outline and the courtyard now take the same colours as the PCB editor in both themes; top copper is the board's red, no longer gold.
- **No headless-runner warnings in Messages (#2468)** — a headless run that drops a window or widget action now logs it at debug level, so it no longer fills the Messages panel.
- **Stock footprints open solved and described (#2468)** — opening a footprint solves its sketch, so the editor shows its constraint state instead of "Sketch not solved". The stock footprints carry a Description, and SOIC-8, QFN-16, the mounting hole and the fiducial a Default Designator.
- **Read cut-off values in Properties and dock tabs (#2468)** — a Properties field shows its whole value in a tooltip and ends a long value in an ellipsis; a dock tab squeezed to an ellipsis shows its full name in a tooltip.
