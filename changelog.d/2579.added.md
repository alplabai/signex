- **Hatched pour fill (#2579)** — a pour's Fill Mode can be Hatched, a square grid of copper lines inside a copper border with its own width and gap; the canvas, Gerber, PDF, 3D view and ratsnest all read the hatch. `set_pour_fill` sets it for an agent or the CLI. A board with a hatched pour saves as `snxpcb/1.12`.
