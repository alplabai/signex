- **Net classes for boards (#2400)** — Tools ▸ Net Classes edits the board's net classes in a table: name, colour, track width, clearance, via and diff-pair settings, and the member nets as chips you pick in or press out. The table is the project's, shared with the schematic, and every edit is one undo step. The Track tool draws a net with its class's track width, and DRC checks its clearance. Every edit is also a command an agent or a script can run.
