- **A pinned datasheet PDF now travels with the library (#1332)** — Saving a row that pins a PDF stores it at `assets/datasheets/<hash>.pdf` beside the library file and, in a git-backed library, commits it together with the row, so the hash resolves after a clone. Nothing is written when you pick the file, only on Save; a file that is not a PDF is refused on the Datasheet tab, and a server library, which keeps no local files, asks for a URL instead.
