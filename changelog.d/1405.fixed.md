- **A pinned datasheet PDF now travels with the library** — Saving a row that pins a PDF stores it at `assets/datasheets/<hash>.pdf` beside the library file and, in a git-backed library, commits it together with the row, so the hash resolves after a clone (#1332). Nothing is written when you pick the file, only on Save; a file that is not a PDF, or is over 64 MB, is refused on the Datasheet tab and in Messages. A library that keeps no files beside its library file, such as a server library, refuses the Save with a message to use a URL, before any file is written. If the commit fails the row is not saved and stays unsaved in the editor.
