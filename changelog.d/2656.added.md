- **Net class conflicts and directives on paper (#2656)** — when two directives give one net different net classes (two Net Parameters directives, a Net Parameters directive over a Net Blanket, or two Net Blankets), on one sheet or on two sheets of a project, the net still takes the class of the first in rank (Net Parameters before Net Blankets, each in sheet order, the sheets of a project in key order) and a new ERC warning, Net class conflict, names the overridden directive and the winner. The finding can be waived. SVG and PDF exports and print now draw Net Blankets and Net Parameters flags as the canvas does; the Blankets and Parameter Sets export options show or hide them, and Print Preview redraws when either changes. The shipped ERC profile Signex Default is now 1.4, so a project seeded from 1.3 offers Update from profile. See `docs/SCHEMATIC_DIRECTIVES.md`.
