- **Net class conflicts and directives on paper (#2656)** — when two directives give one net different net classes (two Net Parameters directives, a Net Parameters directive over a Net Blanket, or two Net Blankets), on one sheet or on two sheets of a project, the net still takes the class of the first in rank (Net Parameters before Net Blankets, each in sheet order, the sheets of a project in key order) and a new ERC warning, Net class conflict, names the overridden directive and the winner. The finding can be waived. SVG and PDF exports and print now draw schematic directives as the canvas does, each kind behind its own export option: Net Blankets and Net Parameters (renamed from Blankets and Parameter Sets) are on by default, the new Compile Masks and Differential Pairs options are off, and Print Preview redraws when any of them changes. The shipped ERC profile Signex Default is now 1.4, so a project seeded from 1.3 offers Update from profile. See `docs/SCHEMATIC_DIRECTIVES.md`.
