- **Text boxes are as wide as the text, in the font it is drawn in (#2023)** — the box of a reference, value, note or label was estimated at a fixed width per character, narrower than the shaped text since font size became the cap height. Hit boxes, selection, box select and the sample-layout checks now use the shaped advance of the family the text draws in (its own font, else the sheet default font; an uninstalled font is boxed in the bundled face that draws instead), and re-measure when the default font changes, on undo and on redo. Global and hierarchical label flags, and their text offset in the PDF and SVG export, follow the measured text width too, so they are about 14% shorter around Iosevka text than before.
