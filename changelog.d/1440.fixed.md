- **BOM and footprint bake fixes (#1376)** — `include_dnp` alone now lists DNP parts, which count as not fitted; a clockwise silk arc whose start angle is greater than its end (for example CW 90° to 30°) no longer bakes as the 300° complementary arc; tagging every edge of a closed outline bakes it once per layer instead of once per edge, and a pour or board cutout whose clearance or corner radius cannot be evaluated is skipped with a warning instead of being baked at 0; an array's source pad is no longer baked twice, and is baked normally when its array is skipped; and ratio and angle sketch parameters keep their units when baked. Behaviour changes to know about: a fitted part with `in_bom` or `on_board` off is now dropped from default exports (it is listed, as not fitted, only with the not-fitted option), and a unitless parameter reads as a plain number, falling back to millimetres where a length is expected.
