- **Class matrix, rule sets and presets in the Rules manager (#2398)** — The Clearance sub-tab has a Matrix view: one clearance per pair of net classes, written as a `class == "A" and other_class == "B"` rule, with each empty cell showing greyed what the pair needs without it and an object sub-grid (track, pad, via pairs) per cell. Named rule sets write their limits once and apply them to classes or nets; changing a set rewrites every rule it wrote. Presets (the Standard, Advanced and HDI tiers, and any rule profile holding DRC rules) show the rules they add, change and remove before they are applied. Each edit is one undo step. Agents drive it with `rules_matrix_get`, `rules_matrix_set`, `rules_set_create`, `rules_set_edit`, `rules_set_apply`, `rules_preset_diff` and `rules_preset_apply`.
