- **A wire's own width beats its net class width (#2026)** — the width order is now explicit width, net class, project default, built-in, so a wire drawn with a set width keeps it inside a net class. This reverses the order #1946 set, where the class width replaced the wire's own. Exported junctions use the canvas size, so a default junction prints as large as it is drawn.
- **Net class line style has a Default (#2026)** — a net class's Line now offers Default, which follows the project's wire line style; Solid, Dashed and Dotted are explicit and override it. Existing classes keep their look.
