- **The schematic grid shows again, and a hover no longer redraws the sheet (#1993)** — The grid was painted under the opaque paper since #1968, so a new sheet showed no grid. It is now drawn after the paper, and grid lines stay inside the paper edge. The paper, grid and sheet frame are rebuilt only when the camera moves, not on every cursor move. The grid dots are not batched into one path, because that measured about 3x slower in a debug build. Whether a release build zooms smoothly has not been measured yet.
