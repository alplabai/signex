- **A row edit no longer skips its version bump when the stored row cannot be read (#1939)** — the edit is refused with the reason in Messages instead of being written with no word that the footprint, Manufacturer or MPN changed, and a row edit reads the stored row once instead of twice. Opening a sheet builds the part checks once per library rather than once per part, a lock file that cannot be removed with a deleted library says why in Messages, and a delete that found nothing on disk no longer reports editors as lost. The limits of the version guard are written down in `docs/architecture/library-part-follows-row.md`.
