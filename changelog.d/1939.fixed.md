- **A row edit no longer skips its version bump when the stored row cannot be read (#1939)** — the edit is refused with the reason in Messages instead of being written with no word that the footprint, Manufacturer or MPN changed, and a row edit reads the stored row once instead of twice. Opening a sheet builds the part checks once per library rather than once per part, a lock file that cannot be removed with a deleted library says why in Messages (once), a delete that skips the folder clean-up no longer lists the project's own folders as left over, and a delete that found nothing on disk words the dropped-editor line as "already gone" instead of "deleted". The limits of the version guard are written down in `docs/architecture/library-part-follows-row.md`.
- **A symbol or footprint editor edit made while its library is being renamed or deleted is refused (#1939)** — Messages names the library and the editor stays as it was, instead of the edit being kept and reported as lost afterwards.
