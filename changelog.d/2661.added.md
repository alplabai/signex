- **Differential pair classes are edited on their preview** — in Design ▸ Differential Pair Classes…, the width, gap, impedance and tolerance written on the board-style preview can be clicked and typed (Enter or Tab commits, Esc cancels), a handle on the N trace drags the gap, and an expand button draws the pair larger. A value set on the drawing is the same edit as its field, so OK still applies the whole dialog as one undo step.
