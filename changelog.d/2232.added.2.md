- **New PCB and New Schematic setup dialogs, saved setup profiles (#2232)** — New PCB now opens a dialog prefilled from the project's setup (profile cards, rule template, copper layers, thickness, clearance, track, via and drill, stack-up preview) and makes the board with the values shown; Cancel makes nothing. New Schematic (File ▸ New ▸ Schematic, Projects ▸ Add New ▸ Schematic) opens the same kind of dialog for sheet size, orientation, title block and designator standard before asking where to save. Save as profile... in these dialogs, the New Project dialog and Project Options stores the values under a name in your settings; saved profiles appear next to the built-ins in every project and can be removed from their card. A project records only the id of its default profile. Headless `new_pcb_document profile=<id>` and `new_schematic_sheet profile=<id> [name=<stem>]` do the same without a dialog. See `docs/PROJECT_SETUP.md`.
