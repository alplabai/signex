- **Agent and CLI schematic placements use the project defaults (#2326)** — a label, port, line, rectangle or wire placed by an agent or the CLI with operands takes what its operands name and the project's schematic defaults for the rest (text size and font, unrotated, left and bottom justified, shape width and fill, a default-width wire), no longer whatever the person's pre-placement form holds at that moment. Placing by hand is unchanged: a click still uses the form.
