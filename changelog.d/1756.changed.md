- **Three more reads leave the update loop (#1756)** — opening a sheet from the Navigator, Up Hierarchy, net navigation, Find, the command palette's search reveal or sheet back/forward now reads the file on a background job and makes the jump (placement, selection, centring, history step) when the sheet arrives; a missing or unreadable sheet is said in the Messages panel and a history step to it drops that entry. Renaming a project file no longer checks for a taken name inside the window: the background move does, right before it moves, and says so in the dialog without overwriting anything. Picking an alternate symbol for a library row resolves the default and picked symbols on a background job; a pick is refused with a visible message when the row was edited, or the preview closed, while they were read.
