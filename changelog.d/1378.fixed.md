- **Keymap correctness (#1378)** — Ctrl shortcuts now match on Windows and Linux. Editing one of several bindings for a command changes only that binding. A shortcut that is also the start of a longer chord (`T A` / `T A E`) now waits for the next key instead of hiding the longer one: it fires when a key that does not continue the chord is pressed, or after an 800 ms timeout, and Esc, a mouse press, a window focus change or a blocking modal drops it without firing. Unbound commands are no longer listed as shortcuts or shown in menus, the context menu or the start screen. A new keyboard-shortcuts backup is always made (`.bak`, `.bak.2`, …) and Restore and Discard act on the most recently written one. The logo key is labelled Cmd, Win or Super per OS on screen but always saved as `Cmd`, and a bare Shift or Ctrl press no longer cancels a pending chord.
