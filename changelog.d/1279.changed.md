- **Breaking: schematic sheets with Schematic Refinement content are saved as `snxsch/1.3` (#1279)** — a sheet that holds a harness connector, harness wire or harness-typed sheet entry, a union, a Bezier, dimension or table drawing, a Net Parameters directive, or a Net Blanket or Differential Pair using one of their new settings is saved as `snxsch/1.3`. An older Signex opens such a sheet read-only rather than dropping what it cannot show. Sheets without any of it save exactly as before. A union member that names an object no longer on the sheet, and a harness type set for a sheet entry that is gone, are dropped when the sheet opens, and Messages lists each one. The project file keeps its `snxprj/1` format: channel naming, harness definitions and differential pair classes are saved under one new `schematic_design` key, only when set, and an older Signex keeps that key when it saves the project.
- **Breaking: a sheet symbol designator that reads `Repeat(<channel>, <from>, <to>)` now repeats its sheet (#1279)** — an existing design whose sheet symbol already used that text as a plain name now compiles to one channel per number, so its netlist, BOM and designators change (`CH1_R5`, `VOUT_3V3_CH1`). Rename such a sheet symbol to keep the old netlist.
