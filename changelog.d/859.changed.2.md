- **Renaming and deleting from the project tree no longer freeze the window (#859)** — renaming a sheet, PCB, primitive, library or project, and deleting a file or library, now move or remove the file on a background thread, and open tabs, engines and project entries follow once it finishes. While one is running, saving, restoring or reopening that file, starting a second rename or delete of it, and library edits during a library rename are refused with a Messages line naming the cause; edits made meanwhile travel with the renamed document. A project or tab closed while it runs is handled by what is open when it finishes, and a library rename the app cannot follow is moved back off the UI thread. Failures still reach the Messages panel with the same text.
