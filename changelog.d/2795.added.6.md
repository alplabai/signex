- **Design Notebook Python cells, without the runtime yet** — a notebook can hold `#python(label: "...")[```python ... ```]` cells that read schematic values with their units, such as `component("L1").value`. Cells run only on Run, Run all and PDF export. A result is cached until the cell or a value it read changes, and an out-of-date result is shown greyed with the change named. The sandbox refuses starting programs, network access and files outside the project. A notebook from outside the project asks before its cells run. The Python runtime itself is not built yet, so cells show the slim-install state.
