- **Sheet and project variables (#1987)** — the project's Parameters are its variables, and a sheet can now have its own in Document Options ▸ **Parameters**, under **Sheet Variables**; a sheet variable replaces the project variable of the same name on that sheet. A value starting with `=` is an expression (`= VCC / 2` shows `1.65V` when `VCC` is `3.3V`), in a variable, a title-block field or a text note: the value you typed is saved and the result is drawn on the sheet, in the PDF, SVG and print preview. A value that does not evaluate, such as two variables that refer to each other, shows its error under the field and in the Messages panel. `${NAME}` and `@{name}` read the same variables.
