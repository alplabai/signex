- **Sketch solver: zero-length lines and a deterministic solve limit (#685)** — A point-on-line or point-to-line constraint on a line whose endpoints coincide now reports "line … has zero length" (naming the line, in the Properties strip and the Messages panel) instead of "solver internal error: initial residual: entity … not found". The 50 ms wall-clock limit is replaced by a work budget counted in residual evaluations (`Solver::work_budget`, default 2,000,000 per LM run), so the same sketch now solves, or fails with the same "exceeded its work budget" error, on every machine and every run; a slow or loaded computer no longer turns a solvable sketch into a timeout.
