- **Sketch solver: zero-length lines and a deterministic, bounded solve (#685)** — A point-on-line or point-to-line constraint on a line whose endpoints coincide now reports "line … has zero length" (naming the line, in the Properties strip and the Messages panel), also when every point involved is fixed, instead of "solver internal error: initial residual: entity … not found". The 50 ms wall-clock limit is replaced by one work budget per solve (`Solver::work_budget`, default 125,000,000 work units, counting residual evaluations and the dense linear algebra), shared by the first run, the retry, the offset undo and conflict narrowing, so the same sketch solves, or fails with the same "exceeded its work budget" error, on every machine and every run. Measured in release on an Apple-silicon Mac, a solve that exhausts the budget takes 96 to 123 ms; a 40-point chain (50 ms), a 16-rectangle grid (16 ms) and a small conflict (9 ms) solve as before. The analysis of a converged sketch is outside the budget, so an already-satisfied large sketch is never refused for its size (92 ms at n = 574 under-constrained, 400 to 520 ms at n = 510 fully constrained, as before). A sketch that still needs solver steps, one of which exceeds the budget (n of about 500 and up), is reported as "sketch too large for the solve budget" with the work it needs. When the budget runs out while the retry's start offset is being taken back out of the solution, the solve now fails instead of returning the offset geometry.
