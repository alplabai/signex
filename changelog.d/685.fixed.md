- **Sketch solver: zero-length lines and a deterministic, bounded solve (#685)** — A point-on-line or point-to-line constraint on a line whose endpoints coincide now reports "line … has zero length" (naming the line, in the Properties strip and the Messages panel), also when every point involved is fixed, instead of "solver internal error: initial residual: entity … not found". The 50 ms wall-clock limit is replaced by one work budget per solve (`Solver::work_budget`, default 150,000,000 work units, counting residual evaluations and the dense linear algebra), shared by the first run, the retry, the offset undo, conflict narrowing and the DOF analysis, so the same sketch solves, or fails with the same "exceeded its work budget" error, on every machine and every run. Measured in release on an Apple-silicon Mac, the full budget is about 130 ms and the worst exhausting solve took 139 ms; a 40-point chain (49 ms), a 16-rectangle grid (16 ms) and a small conflict (9 ms) solve as before, and a 32-rectangle grid (n = 254, 104 ms), which the old limit gave up on at 67 ms, now solves. A sketch whose single solver step exceeds the budget is reported as "sketch too large for the solve budget" with the work it needs.
