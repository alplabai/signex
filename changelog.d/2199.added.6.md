- **DRC on demand for agents and the command line (#2199)** — `check_drc document=<board>` checks one board as Run DRC does (the project's net classes and DRC rules, a closed board read off the UI thread) and answers with the same report shape as `check_erc`: each finding's rule (`builtin::clearance`, or `user::<name>` for a written rule), its severity from the DRC rule model, message, evidence, items and a key that stays the same when an item moves. `signex-cli run demo.snxprj check_drc --arg document=demo.snxpcb`. `baseline=<run>` lists the findings that are new and gone since an earlier run on the same board. The check writes nothing to the DRC panel or Messages; Run DRC is unchanged.
