- **Design Notebook tab (#2795)** — a project's notebook opens as a document tab: the Typst source with line numbers, colours and error marks beside its compiled pages, which recompile as you type and keep the last good compile on screen under an error. An Outline, Pages and References panel, insert buttons for references, calculations, measurements, figures and blocks with their next free id, a Problems strip, and the compile result in the footer; Source, Split and Preview, with the preview page following the theme while the PDF prints white. A project with no notebook shows two templates and Import .typ files; nothing is written before Save. `notebook_compile`, `notebook_insert` and `notebook_view` do the same from the command line.
