- **The macOS menu bar uses the iced fork's native menu (#2255)** — Signex no longer drives the system menu bar itself; the menus, their shortcut text, check marks and greyed rows look and act as before. The app menu's last row is now the system's "Quit <app name>" (it reads "Quit Signex" in the bundled app and shows the executable name under `cargo run`). If the system menu bar cannot be built, the in-window menu row appears and the Messages panel says why.
