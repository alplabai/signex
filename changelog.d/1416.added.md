- **EN IEC 81346-2 full class codes as a designator standard (#1416)** — Project Options offers **EN IEC 81346-2 (full codes)** beside the single-letter option. New parts get the three-letter class code of their component class (`RAC` resistor, `QAC` transistor, `XDB` connector, ...), and Annotate numbers each code on its own counter (`QAC1`, `QAC2`). The project stores `QAC1`; the schematic and PCB canvases, the BOM, the netlist, the PDF, the board reports, pick and place, the Gerber legend, IPC-2581, ODB++ and the board STEP model show `-QAC1`. The IPC-D-356 test netlist writes `QAC1`, since its 6-character field would cut a signed designator. A `-` typed or given in front of a designator is dropped when it is stored. The codes for display, sensor and battery are provisional. Re-prefix to standard moves placed parts between the single-letter and the full codes. A project saved with this choice is read by an older Signex as an unknown standard and kept unchanged.
