- **EN IEC 81346-2 full class codes as a designator standard (#1416)** — Project Options offers **EN IEC 81346-2 (full codes)** beside the single-letter option. New parts get the three-letter class code of their component class (`RAC` resistor, `QAC` transistor, `XDB` connector, ...), and Annotate numbers each code on its own counter (`QAC1`, `QAC2`). The project stores `QAC1`; the schematic and PCB canvases, the BOM, the netlist, the PDF, the board reports, pick and place, IPC-D-356 and the Gerber legend show `-QAC1`, and a `-` typed in front of a reference is dropped when it is stored. Re-prefix to standard moves placed parts between the single-letter and the full codes. A project saved with this choice is read by an older Signex as an unknown standard and kept unchanged.
