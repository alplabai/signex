- **EN IEC 81346-2 full class codes as a designator standard (#1416)** — Project Options offers **EN IEC 81346-2 (full codes)** beside the single-letter option. New parts get the three-letter class code of their component class (`RAC` resistor, `QAC` transistor, `XDB` connector, ...), and Annotate numbers each code on its own counter (`QAC1`, `QAC2`). The project stores `QAC1`; the schematic canvas, the BOM, the netlist, the PDF and the other schematic outputs show `-QAC1`. Re-prefix to standard moves placed parts between the single-letter and the full codes. A project saved with this choice is read by an older Signex as an unknown standard and kept unchanged.
