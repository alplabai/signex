- **Board sketch mode (#2234)** — Design ▸ Board Sketch, the PCB Active Bar's Board Sketch button, the board's right-click menu or the palette opens the board in sketch mode, with the same sketch tools as the footprint editor (line, arc, circle, rectangle, dimension, constraints, construction) drawn over the board. Mark an edge as the board outline, a circle as a mounting hole (drill, plating, net), and set keepouts and cutouts with Role in Properties. Leave or Apply bakes the sketch onto the board as one undo step; if the sketch does not bake, the reason is shown and the board is left as it was. The board canvas now draws the outline, cutouts and mounting holes as openings, and keepouts as hatched areas.
