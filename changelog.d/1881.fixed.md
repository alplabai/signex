- **A case-only rename and an upper-case sheet extension work on Windows and macOS (#1832)** — Renaming `Sheet2.snxsch` to `sheet2.snxsch` is no longer refused with "A file with that name already exists". The file is the same one, so it moves through a temporary name, and a rename onto a different file or onto a second hard link to the same file is still refused. Opening `PUSHPULL.SNXSCH` no longer fails as an unsupported file type, and a board opened as `Board.SNXPCB` saves clean like any other board.
