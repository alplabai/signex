- **Update PCB from schematic from the command line (#2470)** — `update_pcb_from_schematic dry_run=true` lists every footprint to add, remove, change or swap, every designator, value, net and pad net change as JSON without changing anything; `apply=true` makes those changes as one undo step and answers with the same list of what was done. `document=<project, sheet or board>` picks the project; left out, the active project's board is used, so `update_pcb_from_schematic apply=true` works as before; when the active project has no board, or several projects are open and none is active, the run is refused with the boards to name, and another project's board is never updated in its place. It runs headless, through `signex-cli run` and through a running Signex.
