- **Board print and PDF (#2402)** — File ▸ Print and File ▸ Export ▸ PDF on a board open Board Print / PDF: pick the layer sets (top side, bottom side, inner copper, outline and mechanical), one page per set or all on one page, the bottom side mirrored, 1:1 or fitted to the page, colour or black ink, and whether the outline, the drill holes and a title block show; Export PDF writes it. The command palette has it as Board Print / PDF, and the command-line tool writes one with `export_board_pdf`.
