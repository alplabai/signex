- **Main-menu rows run their command like the keys do (#1922)** — every menu row that shows a shortcut now runs its command id through the command registry, from the main window, an undocked window and the macOS system menu, so a row and its key can no longer drift apart. View ▸ Toggle Grid now saves the choice like the keys and the status bar, View ▸ Fit All in an undocked window fits that window's canvas, Place ▸ Wire and Bus remember the tool as the Active Bar's wiring default, and the alias ids `draw_wire`, `draw_bus`, `place_text`, `draw_graphic_line` and `draw_hierarchical_sheet` share one route (and, for wire and bus, one gate) with `place_wire`, `place_bus`, `place_text_string`, `draw_line` and `place_sheet_symbol`.
