- **Main-menu rows run their command like the keys do (#1922)** — every menu row that shows a shortcut runs its command id through the command registry, from the main window, an undocked window and the macOS system menu, except View ▸ Cycle Grid Size and Design ▸ Electrical Rules Check, whose rows do something other than their id (#1991). A row and its key can no longer drift apart. View ▸ Toggle Grid now saves the choice like the keys and the status bar; View ▸ Fit All in an undocked window fits that window's canvas; Place ▸ Wire, Bus and Junction behave like the Active Bar buttons (they remember the tool as the wiring default and close an open Active Bar dropdown); and the alias ids `draw_wire`, `draw_bus`, `place_text`, `draw_graphic_line` and `draw_hierarchical_sheet` share one route (and, for wire and bus, one gate) with `place_wire`, `place_bus`, `place_text_string`, `draw_line` and `place_sheet_symbol`. Zoom In and Zoom Out are greyed without a schematic or PCB, Annotate Schematics Quietly and Force Annotate without an open sheet, and Document Options outside a symbol or footprint editor in an open library, where each did nothing before.
