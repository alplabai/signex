# Rule file for scripts/check_uifree_state.sh (ADR-0006, "Enforcement": core-bound
# state stays UI-free before its slice). Owned by the maintainers (CODEOWNERS):
# a new `module` line needs Caner's or Hakan's approval.
#
#   struct <path> <Struct> [<field globs>]  scan these fields (comma-separated
#                                           `*` globs, `!glob` excludes; all
#                                           fields when omitted)
#   module <path>                           a signex-app module accepted as
#                                           UI-free; its types become allowed
#                                           field origins and it must pass the
#                                           closure check
#   crate <ident>                           a third-party data crate allowed as
#                                           a field origin
#
# `#` starts a comment.
